PLAYER PROGRESSION

雑魚院卒 → 博士 → 助教 → 准教授 → 教授 → 名誉教授 → 神 → PhD in zuizui

LV.0 · 雑魚院卒
目の前の現象を面白がる。でも問い、証拠、方法、claim の境界がまだごちゃごちゃ。最初の repository を作って世界を分け始める。

LV.1 · 博士
一つの問いを自力で閉じられる。結果が欲しい答えでなくても、STOP や反証を成果として保存できる。

LV.2 · 助教
一つの研究だけでなく、次に何を測るべきかを設計できる。観測・解析・field work を別レイヤーとして扱える。

LV.3 · 准教授
複数 repository が series になる。個別研究を足し算するのでなく、前の問いが次の問いを必然的に生む。

LV.4 · 教授
異なる series の間に bridge を架ける。実証、方法論、理論を混同せず、それでも一つの research universe として読める。

LV.5 · 名誉教授
何を発見したかだけでなく、何を言ってはいけないか、何を後世に残すべきかまで設計できる。失敗系も provenance として残る。

LV.6 · 神
だいたい何でも説明できそうな顔ができる。危険。ここで万能理論を名乗ったらゲームオーバー。自分の理論が壊れる条件を自分で作れるかが最終試験。

TRUE END · PhD in zuizui
肩書きの上位互換ではない。アザミ、花色多型、島、観測、方法論、理論が「自分は何を世界の state として見たいのか」という一つの癖として接続される。最終的に取得したい学位は、自分自身。

GAME RULES

論文数ではなく、研究者としてできることが unlock される。

XP repository を作る、問いを閉じる、再現可能にする、反証を保存する、claim ceiling を守る。成功だけでなく、きれいな STOP も経験値。

SKILL TREE series は専門分野ではなく能力の系統。アザミ／花色多型／島は empirical worlds、観測／方法論／理論はそれらを扱うために獲得した技。

QUEST 1 repository = 1 chapter = 1 quest。巨大な夢を一章にせず、独立した問い・証拠・境界を持った時点で一つの quest になる。

BOSS reviewer ではない。confounding、non-identifiability、selection bias、failed generalization、観測不能性、自分の思い込み。

DEBUFF 「結果が出たから機構が分かった」「精度が高いから現実が測れた」「中心にある repo が一番偉い」。このゲームでは全部 status ailment。
