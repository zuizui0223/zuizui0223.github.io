CHAPTER RULE

章数を増やすのは、説明を細かくしたときではなく、新しい所有単位が生まれたとき。

01 一つの repository が一つの問い・結果・claim ceiling・next question を所有する。したがって一つの chapter に対応する。

02 island の「世界探索 → simulation → 伊豆収束 → secondary analysis → 実証」は5つの説明段階だが、所有 repository は3つなので3章。概念段階をそのまま章数にしない。

03 将来課題は NEXT CHAPTER / repo TBD。実装・証拠・claim ceiling を持つ repository が生まれた時点で初めて正式な章番号を与える。

HOW TO READ THIS MAP

中心にあることも、後の章であることも、正しいことを意味しない。

01 Graphify は問いの継承を示す。科学的証拠は、各 repository の凍結結果と一次文書にある。

02 STOP、反証、未識別も独立した chapter。次の repository が越えてはいけない境界を所有する。

03 NEXT CHAPTER は予告であって成果ではない。repository が作られ、検証契約を持つまでは正式章に昇格しない。
