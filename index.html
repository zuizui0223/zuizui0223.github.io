FLOWER-COLOUR POLYMORPHISM · THESIS SPINE

花色 variation は、座標系を変えるとどんな state structure として現れるか。

01 · fcp Chapter 1 — Where are the states now?
個体群内共存と地理分化を分け、現在の空間上で state がどこに存在するかを置く。

02 · chun Chapter 2 — Where have the states existed through evolutionary time, and what constitutes the same state?
反復転換を進化時間上で追い、同じ可視色と同じ underlying state を分離する。

03 · hotarubukuro Chapter 3 — What becomes visible when one polymorphic state system is resolved across phenotype, spatial scale and ecological context?
一つの花色多型系を解像し、空間・表現型・生態文脈を重ねたときに初めて見える structure を問う。

ISLAND WORLDLINE · GLOBAL → IZU

島シリーズは、比較宇宙を広げ続けるのではなく、伊豆へ収束する。

01 世界の島嶼系を広く探索
response state は branching / same-direction / buffering / decoupling / falsification と多様で、一つの island response に圧縮できない。

02 simulation で一般化
one perturbation ≠ one response。starting state は平均 geometry を組織するが、realized community が応答変異の 80.17% を担う。

03 比較宇宙から伊豆へ収束
同じ島列で network・functional traits・historical phenotype・今後の field experiment まで接続できるため、伊豆を deep anchor として選ぶ。

04 伊豆 secondary analysis
raw matching は source state × community composition で説明され、community 補正後の extra partner sorting は不支持。

05 · shimahotarubukuro 目線を伊豆へ固定した後の実証例
世界比較や simulation の代替ではなく、その先で historical phenotype と field experiment を同じ島列に接続する deep empirical anchor。
