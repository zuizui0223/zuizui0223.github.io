## 根拠付きの肯定的結論

### 1. island — 単一の island syndrome ではなく、二つ以上の応答枝

**状態: まだ暫定（draft PR の formal run）**  
根拠: [PR #142](https://github.com/zuizui0223/island/pull/142)

最新 formal run は trait input **222,688 / 318,885 cells = 69.83%**、reproductive-assurance **48,497 / 106,295 = 45.63%** を用いた。Wave52 からは **+37,771 usable cells**、うち reproductive が **+11,315** 増えているにもかかわらず、H1–H5 の claim ceiling は安定した。

- **H1:** universal syndrome は棄却。
- **H2:** isolation-associated response vector の地域差は pattern level で支持。ただし climate-independent categorical biogeography までは未確立。
- **H3:** broad Palearctic primary response は `observed 4/4 → family-adjusted 4/4 → genus-adjusted 0/4`。現時点では **family より細かい genus-level lineage assembly** が最も強い説明。
- **H4:** area は 16/16 classifications で measurement-sensitive modifier のまま、**0/16** heteroskedastic-null gates pass。capacity/founder mechanism には昇格しない。
- **H5:** independent pollination-channel exposure / visitation / single-visit effectiveness がないため未評価。

生態学的には、古典的な floral island syndrome は少なくとも **reproductive assurance/selfing** と **pollination-associated floral architecture/attraction-access** に分解される。Palearctic では両者が同方向に動きやすいが、Tropical では reproductive assurance が上がっても specialized/attractive architecture が維持・強化され得る。よって `isolation → selfing → floral simplification` の必然的な一本鎖は支持されない。

二次的 architecture では、3 sampled templates の共通 factor が **86.94%（all-analysis）/ 86.44%（direct-only）** の分散を説明する。このため Tropical の bird-/butterfly-/large-bee-like の同時増加を、三つの realized pollinator guild の同時増加とは読まず、主として **shared specialized/attractive floral-architecture dimension** と読むべきである。

**論文化すると:** oceanic separation は一つの universal phenotype を作るのではなく、source/lineage assembly と context-dependent response branches を通じて reproductive assurance と floral architecture を結合・分離する。

### 2. izu-core — richness は粗い regime、composition × state は branch を担う

**状態: 既存結論を修正しつつ強化**  
根拠: [Exact realized-richness hard control](https://github.com/zuizui0223/izu-core/blob/main/docs/CHAPTER2_SUPPORTING_INFORMATION_S19_REALIZED_RICHNESS_20260907.md), [three-result narrative](https://github.com/zuizui0223/izu-core/blob/main/docs/CHAPTER2_THREE_RESULT_NARRATIVE_LOCK_20260908.md)

6 prespecified matching seeds の各々で **96 trajectory pairs × 120 steps = 11,520 snapshot pairs** の realized richness を stepwise に完全一致させた。元の mean richness は mainland-like **14.4140** vs island-like **2.3892**、mean absolute gap **12.0261** であり、99.965% の snapshot で gap があったため、これは強い control である。

結果は prespecified full-clear を通らなかった。**6/6 seeds で ensemble mean response geometry は all-positive** になった。したがって、以前の強い読み「realized richness difference は mixed mean geometry に不要」は反証された。

しかし individual branching は消えない。mixed-sign realizations は **51–65/96**、state × community non-additivity は **42.72–48.51%**、community-realization additive share は **50.04–55.92%**、starting-position additive share は **0.94–2.21%** に留まった。

よって支持される階層は

`realized richness / turnover → coarse mean-regime placement`

`starting state × realized community composition → branch contingency`

である。別の equal-turnover control でも **70/96** communities が mixed、state × community non-additivity **65.61%** が残る。

実系への橋も維持される。Wanshan–Yongxing は pollinator turnover **0.9796**（95% CI 0.9443–1.0000）に対し richness log response ratio -0.1054（CI -1.3218–0.2877）。Ogasawara は turnover **0.6817**（CI 0.4975–0.9653）、richness log RR -0.3146（CI -0.8755–0.4055）。少なくとも二つの source-native context で、partner replacement は単純な richness loss だけでは表せない。

Izu では FDQ → corrected matching が **+1.943**（5-island）/ **+2.059**（post-Oshima 4-island）で、leave-one-island も全て正。一方 matching → pollen は平均 +0.0353 / +0.0342 だが leave-one-island が0を跨ぐ。8 target の matching は全て低下しても、tube は 3 shorter / 4 longer / 1 unchanged、pollen は 4 lower / 4 higher へ分岐する。

**論文化すると:** island community reorganization は、richness による coarse opportunity regime と、composition × plant state による branch allocation を分けて理解する必要がある。

つまり、現時点の present-niche transition concordance は **coarse Japan–Taiwan mean difference や regional state composition ではなく、各地域内の taxon-level climate differences** に担われる。

同時に三形質を同じ9環境軸へ載せた common9 screen では、一つの共通 abiotic driver は現れなかった。

- Orientation: 17 taxa、omnibus **2138/6188 = 34.55%**。static tip-state split は弱く、transition-conditioned result の方が強い。

- Stickiness: 12 taxa、omnibus **116/924 = 12.55%**。GSP +1.278 SD（18/924=1.95%）、BIO12 +1.311 SD（22/924=2.38%）は precipitation-related lead だが、両者 BH **q=0.321** なので探索的。

**論文化すると:** 三つの capitulum traits は同じ historical comparison framework を共有できるが、生態学的 interface は trait-specific であり、同じ climate template に強制すべきではない。

### 4. chun — fine-state organization は反復するが、canonical binary state は反復しない

### 6. PAYOFF — real data で reciprocal-invasion sign logic を一段だけ回収

**状態: 新規に支持された。ただし generic game layer のみ**

## 全リポ横断の統合

### A. 「粗い要約」と「分岐を保持する state」を分ける

今日の複数の結果は同じ構造へ収束する。

- `island`: one syndrome → reproductive assurance と floral architecture の branch
- `izu-core`: richness → coarse mean regime、composition × state → branch identity
- `EAzami`: common climate screen は trait-specific interface を置換しない
- `chun`: coarse colour partition は canonical ではなく、fine phenotype state に組織化が残る
- `EOG`: dynamic truth を static node signature に潰すと prediction が悪化する

つまり、有用な state は「便利な一個の指標」ではなく、**問いに必要な差異を保存している表現**でなければならない。

### B. context dependence はノイズではなく、mechanism の一部

`BALANCE` の pollinator × herbivore、`PAYOFF` の pH × time horizon、`izu-core` の starting state × community、`island` の biogeographic context は、どれも「同じ driver が同じ方向へ効く」モデルを崩している。今後は平均効果だけでなく **どの context で符号・branch・有効な state variable が変わるか**を主対象にした方が研究群全体に一貫性が出る。

### C. negative control が主張を弱めるだけでなく、機構階層を鋭くしている

- `izu-core`: richness-irrelevance を捨てて「regime vs branch」の階層へ
- `EAzami`: between-region explanation を捨てて within-region taxon-level signal へ
- `chun`: privileged binary state を捨てて representation-dependence へ
- `EOG`: generator mismatch を主因候補から下げ、static reuse / identity encoding へ

今日の前進は、positive result の数が増えたことより、**何を原因としてはいけないかが固定され、その残りがより具体的になったこと**にある。

## 理論・観測設計側の更新

生態学的 effect estimate とは数えないが、研究体系の方法論側もかなり整理された。

- `MROD` / `Boundary`: limitation を一つの severity に潰さず、orthogonal states → scientific actions に写像する共通 taxonomy を executable 化。
- `CCOC` / `MLTR` / `MRM`: temporal cut に対して future / history / latent mechanism の responsibility をそれぞれ非循環に定義。
- `CED`: Boundary/MROD/CED を統合した **Evidence** mainline を作り、learning と licensing、objective-relative stopping を分離。
- `V3`: V3/REC/TNOA を統合した **Observation** mainline を作成。
- `CREST`: sparse semantic access と shallow-lake joint prerequisite を通じ、「world に情報が存在する」ことと「使用する grammar から target にアクセスできる」ことを分離。
- `pollipi`: field probability を本番 decision に混ぜず shadow-only で監査できる計測窓を実装。

この群は「もっと測る」前に、**何を答えたいか、現在の表現でそれにアクセス可能か、どの不足なら再測定・別測定・停止のどれを選ぶか**を同じ言語で扱う方向へまとまっている。
