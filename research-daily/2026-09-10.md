## 1. island — Chapter 1 の結論が「draft result」から正式 freeze へ

PR #142 は merge 済みとなり、Chapter 1 の canonical result が main-level の submission freeze に入りました。解析値そのものは昨日報告したものと同じで、**222,688 / 318,885 cells = 69.83%**、reproductive assurance は **48,497 / 106,295 = 45.63%** です。final analysis は run `34232450884`、artifact `10058653212`。

凍結された結論は次の通りです。

- **H1:** one universal floral/reproductive island syndrome は回収されない。
- **H2:** response は context で分岐する。Palearctic では separation とともに accessibility/generalization と reproductive assurance が増える一方、tropical assemblage では reproductive assurance を増やしつつ specialized floral architecture を維持・強化しうる。
- **H3:** Palearctic broad response は `observed 4/4 -> family-adjusted 4/4 -> source-matched genus-adjusted 0/4`。したがって family composition より細かい **genus-level lineage assembly** と整合する。
- **H4:** area は modifier として残るが、heteroskedastic-null promotion は **0/16**。
- **H5:** plant database だけでは pollination-channel causation は同定不能。

さらに `large_bee_like / butterfly_like / bird_like` の三つの plant-architecture scores の source-trained common factor は **86.94%（all-analysis）/ 86.44%（direct-only）** を説明します。これらを三つの pollinator guild abundance の直接証拠として読むのではなく、共有された specialized/attractive architecture 軸として扱う freeze です。

### 何の生態学的問いに答えるか

島嶼化は花の性質を一方向の「island syndrome」へ押すのか、という問いに対し、現在の答えは **no**。reproductive assurance と pollination-associated architecture は少なくとも部分的に分離し、地理的 separation の効果も lineage assembly を介して現れる可能性が高い、というところまで言えます。

### 今日新しく強くなった点

Wave52 の 184,917 usable cells から final 222,688 へ **+37,771 cells**（うち reproductive assurance +11,315）増えても claim structure が変わらず、同時に新規 source acquisition が diminishing returns に入ったため、freeze の根拠が「任意の coverage cutoff」ではなく **inference stability + declining recoverability** になりました。

**判定: `既存結論が強化された`。** 新しい effect direction が出たのではなく、昨日まで draft 扱いだった結論が正式な paper-level claim に昇格しました。

## 3. CREST — 「必要な区別だけ残す state」を最小 quotient として閉じた

CREST は昨日の ecological positioning から一段進み、pure finite temporal-boundary theory の核をかなり明確にしました。

PR #101 の least temporal-cut quotient は、有限 world carrier `Ω`、cut observation `O_t`、事前に宣言した signatures `g_i` に対して、

`ω ~* ω'` iff `O_t(ω)=O_t(ω')` かつ全ての `g_i(ω)=g_i(ω')`

で state を定義します。この quotient は、

1. observation と全 signatures を保存し、
2. それらを保存するあらゆる他 quotient より coarser な **least-information state** で、
3. block relabeling を除いて一意、

という universal property を持ちます。4-world partitions の exhaustive test と canonical sparse semantic-access quotient への specialization regression が入りました。

PR #108 はさらに cut 間 transport を閉じました。deterministic world evolution `φ` が quotient state 上に well-defined transition を誘導する必要十分条件は、

> source-equivalent worlds の像が target でも equivalent であること

です。失敗した場合、それは representative choice で隠す問題ではなく、**source state が target transition を記述するには粗すぎるという state-sufficiency obstruction** です。identity と composition も quotient 上へ降りることが確認されています。

### 生態学的意味

これは「過去を全部 state に持つ」でも「観測時点の coarse label だけ持つ」でもありません。**将来の問い・応答・証拠に必要な区別を事前に宣言したら、それを壊さない最小 state は数学的に一意に定まる**、という整理です。

EOG の fresh failure と直結して見えますが、EOG を CREST の定理で説明し切ったわけではありません。安全な接続は、**representation が予測に役立つかは、その representation が target transition に必要な区別を本当に保存しているかという別問題**だ、というレベルです。

**判定: `新規に支持された理論結果`。** empirical ecology ではありません。
