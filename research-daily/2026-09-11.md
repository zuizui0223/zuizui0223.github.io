## 2. izu-core — system size によって「何が応答差を支配するか」自体が入れ替わる

PR [#345](https://github.com/zuizui0223/izu-core/pull/345) は、`trait_adjustment = 0.03` を有効にしたまま、community system-size multiplier `k={1,2,4,8,16}` を変更し、既存の6 prespecified seeds × 96 realizations/seed で variance hierarchy を検証しました。最初の v1 seed list は設計記述と不一致だったため manuscript admission 前に破棄され、既存 audit と同じ six-seed ensemble に戻した v2 だけが正式結果です。

結果は seed-stable rank crossover でした。

| k | median starting-position share | median community-realization share | median non-additivity | starting > community |
|---:|---:|---:|---:|---:|
| 1 | 2.55% | 72.98% | 24.71% | 0/6 seeds |
| 2 | 10.33% | 48.03% | 41.71% | 0/6 |
| 4 | 27.33% | 23.52% | 49.47% | **6/6** |
| 8 | 42.52% | 18.26% | 40.07% | **6/6** |
| 16 | 55.84% | 12.72% | 31.99% | **6/6** |

つまり small stochastic-community regime では **realized community composition** が最大の additive variation source ですが、pooling を増やすとその成分が縮み、`k=4` から全6 seeds で **plant starting state** が上回ります。

しかも branch heterogeneity は消えていません。mixed-sign realizations は `k=1` で41–51/96、`k=4` で41–58/96、`k=16` でも **28–42/96** 残りました。state × community non-additivity も最大約49.47%です。

### 何の問いに答えたか

**pollinator community stochasticity が弱くなるにつれて、植物応答の差を決める要因の順位は不変か。** 答えは **不変ではない** です。

### 生態学的意味

モデル内では、少数・高変動の pollinator community では「誰がたまたま実現したか」が強く、community averaging が進むと「植物がどの starting state にいるか」が前面に出ます。ただし interaction は残る。したがって island response を一つの driver ranking で固定するより、**regime に応じて dominant determinant が切り替わる階層**として扱う方がよい、という mechanistic support になりました。

### 論文化できる主張

> The ordering of response determinants is itself regime dependent: realized-community variation dominates in small stochastic systems, whereas plant starting state becomes the larger additive component as community averaging increases, while non-additive branching persists.

数値的な `k≈4` はこの synthetic model 固有で、自然界の universal threshold ではありません。

## 3. slk — SCH/BALANCE/BITA/PAYOFF の共通 spine が独立 flagship になった

今日の新規リポ [`slk`](https://github.com/zuizui0223/slk) は、4つの既存理論を単純合併するのではなく、共通部分だけを一つの evolutionary architecture hierarchy に切り出しています。

```text
SCH      : shared-coordinate conflict load L
BALANCE  : L > 0, Phi < 0 なら persistent compromise
BITA     : recoverable benefit R と architecture margin Phi = R - K
           quadratic bridge では R = sL
PAYOFF   : architecture value を accessibility / invasion / fixation / occupancy へ運ぶ
```

中心的な新規理論メッセージは「各段階を自動で同一視しない」です。登録された witness では、

- `L > 0` でも `Phi < 0` は可能 — conflict があっても differentiation は得ではない。
- `Phi > 0` でも local accessibility がない場合がある。
- accessible かつ `Phi > 0` でも rare invasion は失敗し得る。
- rare invasion しても reciprocal fixation superiority は保証されない。
- absolute fixation advantage over neutrality でも long-run occupancy superiority は保証されない。

一方、登録された symmetric rare-mutation exponential-Moran process では

`reciprocal fixation ordering <=> stationary monomorphic occupancy ordering`

という invariant が成立します。

### 生態学・進化学的意味

multifunctional trait が conflict を抱えること、形質分化が globally advantageous であること、その分化が local mutational path から到達できること、rare state から侵入できること、固定しやすいこと、長期占有することは、**別々の進化質問**です。SLK はこれを一つの gate ladder にしたため、野外・実験データ側でも「conflict を測ったから specialization evolved と言う」といった飛躍を防げます。

ただしこれは **新しい empirical validation ではありません**。README 自身も empirical claim ceiling unchanged と固定しています。

同時に source repos は residual 独立テーマへ戻りました：`sch` は causal/contextual optima、`balance` は persistence/hysteresis、`bita` は differentiation 後の ecological mechanism、`payoff` は continuous architecture と spatial/temporal dynamics を担当します。
