## 1. `egwee` — fragmentation が connectivity・fitness・genetic state を同じ系で同方向に動かした

今日もっとも明瞭な新規 empirical result は [`egwee` PR #8](https://github.com/zuizui0223/egwee/pull/8) です。*Serapias lingua* の9 populations を、原論文自身が定義した anthropic **C/F/G** と natural **A/B/D/E/H/I** に分け、population を独立単位として Hedges' g を再構築しました。

- **fruit set (F): g = -4.5541**, variance = 1.9814
- **pollen immigration (C): g = -10.0990**, variance = 7.7850
- **adult observed heterozygosity (G_adult): g = -26.0725**, variance = 49.0553
- F_IS sensitivity も orientation 後 **g = -8.0535**（同じ populations なので H_O と独立効果として joint pooling しない）

重要なのは、4,956 paternity assignments を n として水増しせず、**independent unit は 3 anthropic vs 6 natural populations** に固定していることです。また従来の `-log(area)` gradient C/F は同じ観測から作る sensitivity representation に格下げし、primary binary contrast と同時にプールしません。

### 生態学的に何が言えるか

この一研究では、anthropic / fragmented context が **pollen-mediated connectivity の低下 → reproductive output の低下 → standing adult genetic diversity の低下**という複数レイヤーで同方向に現れています。つまり habitat alteration の影響を「遺伝だけ」「繁殖だけ」に分離せず、**interaction/connectivity–fitness–genetic state を同一系で結ぶ multilayer propagation** の実例として使えます。

ただし低N一研究です。特に H_O の巨大な標準化効果は group 内SDが小さいことの影響が大きく、variance も大きいので influence warning を外せません。論文の安全な主張は、**one source-defined same-system contrast recovers concordant deterioration across C, F and G_adult** までです。

## 4. `crest` — prerequisite graph が「どこに interaction が出てよいか」を決める

[`CREST PR #127`](https://github.com/zuizui0223/crest/pull/127) は、future query の prerequisite set と semantic access を分離する新しい theorem を追加しました。

Shannon order では prospective coalition game が weighted unanimity games の和として factorize し、**Möbius support は declared prerequisite set `R_f ∪ {F}` にしか現れない**。semantic coverage / occupancy は interaction の「場所」ではなく重みだけを変えます。1/4 cell、decoder depth 10 の canonical witness では pure three-way Shannon dividend = **2.5 bits**。

一方、minimal two-cell witness の Rényi interaction leakage は

`D_q = 1 - 2/(1-q) log2(1/2 + 2^-q)`

で、zero は **q=1 のみ**。q<1 で負、q>1 で正、q→∞ で1です。つまりこの witness では Shannon が prerequisite-support faithful で、非Shannon Rényi order では declared graph にない distribution-induced interaction が出ます。

生態学的には、interaction decomposition の前に「どの prerequisite interface を model に保持したか」を明示しないと、**measurement/access pattern が biological interaction に見える**危険がある、という理論的な境界になります。

## 全リポ横断で昨日より一段進んだこと

昨日は、**lower-layer positive を upper-layer claim に勝手に昇格させない**という claim ladder が主題でした。

1. `egwee` は一つの biological system で **C/F/G の multilayer concordance** を閉じた。
2. `balance` はそのような conflict / mediated-selection pattern の **independent-system recurrence** を3 clustersまで定量化した。

**single-system multilayer effect → cross-system recurrent pattern → mechanism identity**

これは研究全体にとって良い状態です。「証拠が足りない」のではなく、**どの証拠がどの claim level を閉じ、次にどんな観測・介入が必要かを定量的に指定できる**ようになっています。

1. **EGWEE / *Serapias lingua*** — source-defined 3 vs 6 population contrast で pollen immigration `g=-10.10`、fruit set `g=-4.55`、adult H_O `g=-26.07` が同方向。fragmentation/anthropogenic pressure の multilayer propagation を同一系で初めて強く可視化。
