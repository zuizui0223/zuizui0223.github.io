## 1. `azami` — taxonomy のまとめ方を変えても Chapter 1 の主要構造が残った

今回もっとも submission-ready な positive result は、Chapter 1 v3 の **WCVP authority-taxonomy sensitivity** です。primary analysis 自体を差し替えず、frozen 46,276 observations / 259 source taxa を既に固定済みの WCVP name-resolution table に outcome-blind に結合し、unique accepted key が取れたものだけで再解析しました。

- retained observations: **40,785 / 46,276**
- uniquely resolved source taxa: **245 / 259**
- accepted WCVP taxa after synonym collapse: **238**
- 複数 source label が同一 accepted taxon にまとまったもの: **7 taxa**
- direct integration の complete common cohort: **1,415 observations / 38 taxa**

### Gate 1 — cross-scale relation geometry

- matrix-alignment rho = **0.293179**
- one-sided QAP **P = 0.0385**
- bootstrap median rho = **0.265251**
- bootstrap 95% CI = **[0.008745, 0.490631]**

事前条件をすべて満たして **PASS**。source-assigned cohort より alignment は弱まるものの、正の cross-scale geometry は残ります。

### Gate 2 — among-taxon integration > within-taxon integration

- median within-taxon RV = **0.002594**
- median among-taxon RV = **0.044057**
- **32 / 36** relations が among taxa で強い
- bootstrap difference median = **+0.067758**
- 95% CI = **[+0.036905, +0.121980]**
- bootstrap replicates with among > within = **1.000**

これも **PASS**。

### Gate 3 — ecological anchors

- floral chroma × shortwave radiation: n=**131 taxa**, beta=**−0.327859**, BH q=**0.00675**
- presentation angle × annual precipitation: n=**129 taxa**, beta=**+0.307370**, BH q=**0.00675**

両方とも sign と multiplicity-adjusted support を保持して **PASS**。

### 生態学的意味

今日強くなったのは新しい環境効果ではなく、**visible-phenotype integration の scale dependence と2本の ecological association が、source label の synonym / accepted-name grouping に依存した人工物ではない**という点です。

論文では、

> Scale-dependent visible-phenotype integration and the retained radiation/precipitation associations are robust to a predeclared authority-taxonomy remapping and synonym collapse.

まで強く言えます。一方、misidentification、species boundary、hybrid/cytotype、ancestry、adaptation、causal mechanism はこの sensitivity では解決しません。

## 2. `egwee` — fragmentation の C→F 伝播に「減衰」の候補が2独立系で出た

昨日は *Serapias lingua* 一系の C/F/G_adult concordance でした。今日は `Brosimum` が C/F effect-unit contract を満たし、**2 independent clusters** で connectivity/movement (C) と reproductive function (F) の相対的な落ち方を比較できるようになりました。cluster 内 covariance を保持し、4 effect rows を独立 n として扱っていません。

`delta(F−C) = g_F − g_C` とすると、

- **Serapias**: +**5.544924**, variance 4.256507, 95% CI **[1.501263, 9.588586]**
- **Brosimum**: +**1.034598**, variance 0.649179, 95% CI **[−0.544577, 2.613773]**

2/2 systems で C<0、F<0、かつ **C の方が F より負**です。diagnostic fixed-effect combination は delta=**+1.631458**、95% CI **[0.160477, 3.102439]** ですが、Q(df=1)=**4.1468**、descriptive I²=**75.9%** と cluster 間差も大きいです。

したがって現時点の claim は、

> 2 independent plant systems show concordant fragmentation-associated deterioration in both connectivity and reproductive function, with connectivity more strongly reduced than realised reproductive function in both systems.

まで。**2 clusters から grand mean や一般法則は出しません**。生態学的には、fragmentation effect が下流へそのまま同じ強さで伝わるのではなく、reproductive function までの間に compensation / nonlinear buffering があり得る、という次の仮説が見えました。次の独立 cluster として `Spondias` の covariance recovery が最も情報価値が高いです。

## 3. `chun` — 花色の反復可能性は「中間解像度」に集まる候補。ただし retrospective

cross-radiation evidence を、exact gene ではなく **pigment pathway region** まで一段集約した tier analysis が入りました。

### hue / hydroxylation

M1 matched systems では Iochrominae、Cape Erica、Petunieae の **3/3** が branching/hydroxylation machinery に対応。Petunieae の preregistered hue endpoint は 53 anthocyanin-positive taxa で `BRANCHING_HUE` を選び、AICc margin = **11.6028**。Ipomoea の3独立 blue/purple→red origins も F3'H regulation の低下を示し、M1+M2 の system tally は **4/4**。

### pigment loss / depletion

Cape Erica の6 white/depletion taxa は exact node では UDP-GST 2 / DFR 2 / ANS 1 / bHLH 1 とばらけます。しかし pathway-region では **5/6 structural-late、1/6 trans-regulatory、0/6 F3'H hue-branch**。Iochrominae も downstream/late module に集まり、Petunieae raw amount は AICc margin **0.4444** で unresolved のままです。

Aquilegia / Epimedium の外部 stress tests まで含めると、M1+M3 で downstream/output/regulatory support **4/5 systems**、unresolved 1/5、supported early-core/hue-branch counterexample 0/5。

ここから、

`coarse visible state` → sharedness weak  
`fine biochemical phenotype dimension` → structured  
`pathway region / functional module` → recurrent  
`exact causal implementation` → heterogeneous

という hierarchy が候補になります。

ただし最大の boundary は、M2/M3 pathway-region synthesis が **source results を見た後の retrospective / hypothesis-generating analysis** であること。これは今日「一般則が証明された」結果ではありません。次の外部 radiation では phenotype dimension・pathway-region ontology・support/counterexample rule を **先に freeze してから**見る必要があります。

## 4. `TTF` — training-system leverage は residual false transfer の原因ではなかった

TTF-C の heterogeneous geometry failure に対して、「total support は足りても、局所的に一部 training system へ依存しすぎているのでは」という仮説を、fresh seed 20260921、7 role cells、100 worlds/cell、1,999 aggregate bootstrap resamples、20-way leave-one-training-system-out で検証しました。

### private-C leverage — NOT SUPPORTED

- rho(raw_C, loo_score_sd_C) = **−0.2144**, 95% CI **[−0.4032, −0.0204]**
- rho(raw_C, mean_prediction_loo_sd_C) = **−0.2032**, CI **[−0.3721, −0.0270]**

必要だった正方向ではなく逆方向。

### local support concentration — NOT SUPPORTED

- rho(raw_C, dominant training-system share) = **−0.0724**, CI **[−0.2650, 0.1316]**
- rho(raw_C, effective training-system count) = **−0.0247**, CI **[−0.2198, 0.1714]**

### geometry shift の power-loss mechanism — NOT SUPPORTED

geometry shift で C deletion sensitivity 自体は **+0.0007331 [0.0001714, 0.0013051]** 増えますが、raw-C loss は **−0.005566 [−0.013228, 0.002696]** で事前の joint criterion を満たしません。

### bounded positive

shared-mismatch matched worlds では C が M より deletion-sensitive で、差 **+0.0012422 [0.0008917, 0.0016016]**。しかし private-M では **−0.0022525 [−0.0030312, −0.0015301]** なので、これは role-dependent estimator sensitivity です。

したがって、**training-system sensitivity は実在するが、private-C false transfer の causal explanation にはならない**。heterogeneous-geometry TTF-C は未qualifiedのまま、leverage penalty / cap / resampling tuning はこの mechanism line では閉じるべきです。これは ecological result ではありませんが、「もっと tuning すれば直る」という枝を一つきれいに切った方法論的反証です。

## 全リポ横断で昨日より一段進んだこと

昨日は **effect pattern → cross-system recurrence → mechanism allocation** を別 endpoint として分けられるようになりました。

今日はさらに、**その endpoint 自体が「どの representation / resolution で定義されているか」を検証する段階**へ進みました。

- `azami`: species label を WCVP accepted taxonomy に畳んでも primary geometry と ecological anchors は残る。
- `chun`: coarse flower-colour categories や exact genesより、biochemical dimension / pathway region で recurrence が見えやすい候補が出る。ただし retrospective。
- `egwee`: same pressure の影響強度は biological layer C と F で同じではなく、2/2 systems で C の方が強い。
- `TTF`: local support concentrationという representation-level explanationを直接試すと支持されない。sensitivity の存在と failure mechanism は別。

つまり今後は、

> **「シグナルがあるか」だけでなく、「そのシグナルがどの分類・解像度・effect unit・観測表現で不変なのか」を claim の一部として検証する**

という方向がかなり強くなっています。
