## 1. CHUN — 「中間解像度が最適」という prospective rule は Iris で失敗

昨日までの retrospective cross-radiation synthesis から、**coarse visible state より pathway-region のような intermediate resolution に repeatability が集中する**という候補則が出ていました。今日はこれを untouched Iris dataset で prospectively test した結果が閉じました。

169 eligible tips、9,999 permutations で、observed AUC は coarse **0.46173**、intermediate **0.45439**、fine **0.48705**。intermediate − coarse = **−0.00733**、intermediate − fine = **−0.03266**、intermediate signal の permutation p = **0.9718**。さらに fine > intermediate の frozen fail check は **p = 0.0486** でした。

したがって、**「進化シグナルは普遍的に intermediate resolution で最大になる」**という一般則は支持されません。fine resolution が絶対的に良いという意味でもありません（fine AUC 自体も 0.5 未満）。言えるのは、**昨日の intermediate-resolution optimum は prospective replication に失敗した**ことです。

これは Paper 1 の既存 retrospective science を消す結果ではありませんが、一般化の ceiling を大きく下げます。今後は colour phenotype を一軸の resolution ladder として扱うより、hue / pigment presence / organ-specific composition など **phenotype dimension ごとに適切な state representation が異なる**可能性を先に仮説化する方が筋が良いです。

## 2. island — pollination channel ごとの isolation response heterogeneity は N1 で支持されず、H5a を停止

N1 の canonical test は **6,256 rows / 3,150 islands / 225 spatial blocks**、4 confirmatory channels（Bombus, Diptera, flower-visiting birds, non-Bombus bees）でした。

isolation × channel の cluster-robust Wald test は **W = 1.6187, df = 3, p = 0.65516**。descriptive isolation slopes は Bombus **−1.0823**、Diptera **−0.7915**、birds **−0.4926**、non-Bombus bees **−0.1597** とすべて負方向でしたが、**channel 間の傾き差を支持する証拠はありません**。

しかも leave-one-spatial-block-out 225/225、leave-one-source-region-out 217/217 の全削除で p≥0.05。最小 p もそれぞれ **0.1271 / 0.1255** でした。predeclared gate に従い `N1_pass=false`、**N2 は開けず、post-hoc channel relabel / subset rescue も禁止**です。

生態学的には、isolation が pollinator retention に負方向の association を持つ可能性と、**その強さが guild によって系統的に異なる**という mechanism claim は別です。後者は今回支持されませんでした。Chapter 1 は H5a mechanism rescue ではなく、既に強い **where / whether / lineage assembly / bounded hierarchical-depth** の本線へ戻すのが正しいです。

## 3. EGWEE / EGWE — 3-cluster state-separation synthesis は Serapias に依存

primary natural state-separation synthesis は3つの comparable fragmented-vs-reference Hedges-g clusters で full corpus では exchangeability を棄却します。しかし leave-one-cluster-out で、**ML001 Serapias を外すと Fisher p = 0.15119** となり棄却が消えます。

一方、Brosimum を外すと p = **0.00518**、Spondias を外すと p = **0.00583** で棄却は残ります。したがって現在の結論は、

> 3-cluster corpus 全体では state separation が見えるが、その formal rejection は **Serapias inclusion に依存し、leave-one-cluster-out robust ではない**。

です。

Eucalyptus の gradient evidence は Fisher-z family なので、primary Hedges-g family と混ぜて「4 independent positives」にしない修正も flagship に同期されています。昨日の C-loss > F-loss / state-separation の方向性は消えませんが、**cross-system generality の主張は一段狭くする必要があります**。

## 4. PAYOFF — first direct-μ D reference はまだ成立しない

M5 BGI target は response-blind calibration を先に固定してから開封されました。absence ceiling は **0.00081871**、presence floor は **0.40016550**。

SCO7036 の primary BGI ratio は **0.00099757** で absence ceiling をわずかに上回り、frozen rule 上 **UNRESOLVED**。他 marker には clear absent / present があるものの、登録された architecture class の primary criterion を救済してはいけません。

そのため `qualified D-reference count = 0` のまま、**architecture-specific inference は HARD CLOSED**。これは「differentiation がない」という biological negative ではなく、**この reference が direct-μ D comparator として資格を得なかった**という結果です。

## 5. TTF — genetic Gate-D は power が足りても type-I gate を通らず、outcomes を開かなかった

frozen Gate-D v0.2 は full-shared A=2 cell で rejection 434/500、Wilson 95% lower = **0.83551** なので power gate（floor 0.80）は PASS。

しかし private-null A=3 cell では rejection 37/500、Wilson 95% upper = **0.1003348** で preregistered ceiling **0.10** をわずかに超え、type-I gate が FAIL。したがって status は **NOT_EVALUABLE**、Decker empirical genetic outcomes は未開封です。

重要なのは 0.1003348 を 0.10 に丸めて救済しなかったことです。これは transferable phylogeographic structure が存在しない証拠ではなく、**この frozen design では empirical opening の資格を満たさなかった**という方法論的結果です。

## 6. positive side — 理論・方法は前進

今日の新しい ecological positive effect は少ない一方、理論・方法には実質的な positive がありました。

`adaptive-gain` は sensing-to-selection bridge を線形 `G=aΔg` から、nondecreasing L-Lipschitz lift へ一般化しました。`G ≤ B L Δg` なので、oscillation threshold を超えるには **Δg > G_osc/(BL)** が必要。canonical example では必要 integer gap は **2**、一方 5-world / 4-query / 4-frontier-edge の binary architecture ceiling はすべて gap **1** なので、その全クラスで requested oscillatory regime が no-go になります。これは十分条件ではなく、**insufficient sensing architecture が dynamics を不可能にする必要条件 theorem**です。

`ODSP` は predictive resolution ladder と transfer ceiling を model-agnostic にし、external held-out scores と refit-aware transfer を first-class input にしました。`SCH / BALANCE / BITA / PAYOFF / SLK` では単位変更や極端な値で conclusion が変わらないよう、relative tolerance・dimensionless coordinates・log-scaled propagation へ修復が進みました。これらは新しい biological effect ではありませんが、既存の理論結果を数値実装に依存しにくくしています。

Azores yellow eel の favorable predictive endpoint が main に回収されましたが、これは以前に once-only run で閉じていた既存 endpoint の evidence recovery です。今回の sealed→opened transition ではないため、**今日の新規 empirical conclusion には数えません**。

## 全リポ横断で昨日より何が進んだか

昨日のテーマは「どの representation / resolution なら signal が保存されるか」でした。今日はその一般化を prospectively叩いた結果、かなり重要な修正が入りました。

- CHUN: **universal intermediate-resolution optimum は失敗**
- island: **channel-specific isolation response は失敗**
- EGWEE: **3-cluster generality は influential Serapias に依存**
- PAYOFF: **direct-μ architecture reference は未資格**
- TTF: **power があっても false-positive ceiling を越えれば empirical opening 不可**

したがって研究全体は、

> **「どの解像度・機構・系でも共通する一般則」を探す段階から、一般化を untouched test で破り、どの claim がどの条件の下だけ成立するかを地図化する段階**

へ進んでいます。

これは後退ではありません。retrospective pattern を prospective law と混同しないことで、次の論文はむしろ強くなります。特に CHUN は falsified rule をそのまま残すことで、flower-colour evolution を「一つの optimum resolution」ではなく **dimension-specific state representation** の問題へ更新できます。

1. **CHUN — Iris prospective FAIL**: intermediate AUC 0.4544、fine 0.4871、fine>intermediate fail-check p=0.0486。昨日の intermediate-resolution rule は universal law にならない。

## 次に回収すべき解析 / 検証

**CHUN** は Iris を救済せず、`hue / pigment presence / biochemical composition / organ-specific colour` のどの phenotype dimension にどの resolution が対応するかを outcome 前に分けるのが次です。Ruellia 51-species HPLC arm は outcome firewall が保たれているため、source/tree gate が閉じればこの新仮説の prospective test 候補になります。

**island** は H5a の別 channel subset を掘らず、failed N1 を closure として Chapter 1 v8 の where/whether/assembly-level framing を仕上げ、mechanism は `izu-core` の同一 tagged-plant chain に渡すのが情報価値最大です。

**EGWEE** は同じ Hedges-g effect family を満たす independent primary cluster をあと1–2系追加し、Serapias omission 後も rejection / direction が残るかを確認するべきです。Eucalyptus Fisher-z gradient は別 evidence lane のまま維持します。

**PAYOFF** は M5 を post-hoc threshold で救わず、事前登録済みの orthogonal evidence / 次の candidate route を使って qualified direct-μ D reference を1つ成立させるまで architecture-specific inference を開けないこと。

**TTF** は current Gate-D を結果依存で修正せず、fresh source route で comparable-site support を増やすなら新しい frozen qualification として再スタートすること。今回の NOT_EVALUABLE は biological null に変換しません。
