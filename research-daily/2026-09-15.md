## 1. EGWEE — 4つ目の直接系が入り、layer non-exchangeability は広がった

新しい primary cluster は *Eucalyptus socialis*（ML014）。[commit `7c246838`](https://github.com/zuizui0223/egwee/commit/7c246838ef79c20014e982fcdd00ddd8dbb56f90) で、public family-level numeric rows を開く前に、Monarto 内の **isolated pasture vs small-remnant woodland**、独立単位 = maternal family、G_mating = family `r_p`、F = family mean progeny growth、effect orientation / covariance reconstruction を固定しました。

結果は同じ28 maternal families（fragmented 13 / reference 15）で、

- pollen-donor-diversity support: oriented **Hedges g = −1.0239**, variance 0.1623
- family growth: **g = −0.2718**, variance 0.1449
- paired covariance proxy = **0.05011**（correlation 0.3267）
- G_mating − F の covariance-aware difference: z = **−1.6531**, p = **0.0983**

です。つまり isolated-pasture context では、offspring growth より pollen-donor diversity support の低下が強い方向でした。ただし ML014 単独の layer difference は有意ではありません。

[canonical synthesis](https://github.com/zuizui0223/egwee/blob/main/manuscript/STATE_SEPARATION_SYNTHESIS_RESULT_2026-09-13.md) は direct fragmented-vs-reference Hedges-g cluster を4系に拡張しました。cluster p は Serapias 0.003545、Brosimum 0.199117、Spondias 0.174068、Eucalyptus socialis 0.098318。Fisher combination は **χ²=22.6477, df=8, p=0.003847** で、現在の4-cluster corpus は biological response layers の exchangeability null を棄却します。

ただし leave-one-cluster-out はまだ完成していません。Serapias を除くと **p=0.07777** で棄却が消えます（昨日の3-cluster状態では0.15119）。Brosimum / Spondias / ML014 を除く場合はそれぞれ 0.00351 / 0.00392 / 0.00621。したがって新しい系は evidence breadth を明確に増やしましたが、**一般則として LOO robust になったとは言えません**。

### 生態学的問いと論文化

問いは「fragmentation の影響は connectivity / reproduction / genetic state に同じ強さで伝わるのか」。現在の4系は、layer response を同一の exchangeable effect と見るより **multilayer state separation** を支持します。ただし universal layer ordering や causal operator sequence は未同定です。

論文 claim は、`Across four directly comparable fragmentation systems, biological response layers are not exchangeable at the corpus level, although the inference remains sensitive to the Serapias system.` が上限です。

## 2. CHUN — biochemical representation では fine composition が情報を保持した

[commit `85ac58f5`](https://github.com/zuizui0223/chun/commit/85ac58f5b06fdeaec93964e35758a45a556da5bc) は Petunieae の biochemical hierarchy を同じ three-resolution estimator に通しました。これは **retrospective standardized training** であり、新しい prospective replication ではありません。

59 ingroup taxa から rare fine states を除いて **47 tips**。coarse と intermediate はどちらも 6 absent / 41 present の同じ partition に崩れました。一方 fine は6つの common compound patterns を保持しました。

- coarse AUC = **0.51893**, p = 0.1985
- intermediate AUC = **0.51893**, p = 0.1985
- fine AUC = **0.69956**, p = **0.0001**
- fine − runner-up = **+0.18064**, joint permutation p = **0.0001**

したがってこの biochemical representation では、anthocyanidin の「有無」や粗い class presence より **exact compound composition** が強い phylogenetic same-state structure を保持しています。

ただし [cross-representation status v0.4](https://github.com/zuizui0223/chun/commit/676e74dd65bbc11596325a6c9e708f03381bc54c) はかなり厳しく境界を置きました。exact-profile completion は30 unitsありますが、内訳は visible-colour 28、biochemical 1、mixed pigment/hue 1。visible 28 clades も coarse 3 / intermediate 0 / fine 3 / tied 6 / no-signal 16 と heterogeneous です。biochemical が1系しかないため、representation-type moderator は leave-one-out では識別不能です。

### 生態学・進化学的問いと論文化

昨日 Iris が universal intermediate optimum を prospectively 否定した後、今日の Petunieae は「では fine が普遍的に最良」という反対則を作る結果ではありません。むしろ、**進化的予測可能性は phenotypic representation に依存し、単一の普遍最適解像度はない**という主線を強くします。

論文 claim は `No universal scale maximizes predictability; a biochemical representation can preserve strong fine-state structure that coarse summaries erase.` まで。`biochemical -> fine` の一般則はまだ禁止です。

## 3. island — H3 は genus-level assembly transition として定量化された

[Chapter 1 effect fingerprint](https://github.com/zuizui0223/island/blob/main/docs/chapter1_response_fingerprint_atlas_20260914.md) は frozen PR142 result から新しい p 値を作らず、family→genus adjustment の effect attenuation を定量化しました。

- total genus attenuation: **78.8–85.9%**
- median: **81.3%**
- family-adjusted remainder に対する conditional genus attenuation: **70.6–79.1%**
- median: **75.7%**

つまり Palearctic two-axis response は family adjustment では一部しか消えず、**最も大きな減衰は family から source-matched genus へ移る段階**で生じます。これは H3 の `observed 4/4 -> family-adjusted 4/4 -> genus-adjusted 0/4` を、単なる gate pattern ではなく effect-size geometry として強化します。

一方、outcome-blind GloBI source-breadth shortcut は、24,577,183 raw interaction rowsから714,785 explicit flower-interaction rows、2,228 genus breadth estimatesを構築して effort matching まで行いましたが、**0/4 context × stratum cells** が promotion rule を通過。したがって「source genera の sampled partner breadth が広い/狭いから H3 が出た」という単純説明は昇格しません。

さらに [H5c result lock](https://github.com/zuizui0223/island/blob/main/config/chapter1_h5c_observed_result_lock.json) は唯一 prequalified された Palearctic direct-only/native-nonendemic cell で biotic-vs-wind specificity を否定しました。

- distance × biotic interaction = **+0.06495**
- robust SE = 0.07921
- 95% CI **[−0.09030, +0.22020]**
- p = **0.4122**
- 133 unique islands / 23 clusters

これは昨日の N1 channel-heterogeneity FAIL と同方向に、**global database から pollinator-specific H5 mechanism を救済しない**結果です。pollinator irrelevance を証明したわけではありません。

### 生態学的問いと論文化

Chapter 1 は「island syndrome の普遍的 within-lineage adaptation」より、**geography-dependent assemblage response + genus-level lineage assembly** を強く支持する形へ収束しています。mechanism は global database から無理に引き出さず、Izu の transition-linked field chain に渡すのが筋です。

## 4. ODSP — transfer ceiling は strong signal では正確、weak/heavy-tail では保守的

[transfer-ceiling receipt](https://github.com/zuizui0223/odsp/blob/main/TRANSFER_CEILING_OPERATING_CHARACTERISTICS_RECEIPT.json) は 1,000 simulations/scenario、6 groups、familywise 95% の mixed known-truth benchmark を凍結しました。これは生態学的 evidence ではなく方法性能です。

- strong full transfer, 20 blocks/group: exact recovery **0.986**, overreach 0
- strong full, 50 blocks/group: **1.000**, overreach 0
- weak full, 20 blocks/group: exact recovery **0.011**, underreach **0.989**
- coarse-null normal: exact coarse recovery **1.000**, overreach 0
- coarse-adverse normal: exact coarse recovery **1.000**, overreach 0
- coarse-null t3 heavy-tail: exact coarse recovery **0.588**, underreach **0.412**, overreach 0

したがって現在の lower-bound transfer ceiling は **false promotion をよく抑える一方、弱い改善と heavy-tail で強く underreach する**ことが明示されました。次の方法課題は one-sided familywise lower bootstrap-t が power を戻しつつ overreach control を保てるかです。
