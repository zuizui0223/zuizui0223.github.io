## 1. island — native assembly と contemporary observed flora を初めて明確に分離できた

今日の最大の前進です。Chapter 1 は一日で P1 → P2 → P3 の三段防御を閉じました。

### P1: genus-level structure は任意の grouping complexity だけでは説明しにくい

[PR #226](https://github.com/zuizui0223/island/pull/226) では、Palearctic H3 の genus attenuation を、同じ family 内で genus 数と group size を保った **matched pseudo-genus** と比較しました。

- valid permutations: **2,000/2,000**
- true-genus conditional attenuation: **0.72066**
- matched pseudo-genus null median: **0.22434**
- null ≥ observed: **57/2,000**
- one-sided randomization **p = 0.02899**

したがって、昨日までの「family→genus で signal が大きく落ちる」は、単に細かい partition を増やせば何でも起きる現象ではなく、**実際の genus boundaries に結びついた構造**を持ちます。ただし paired spatial-block 95% CI は追加 family→genus attenuation の正確な大きさについて0を跨ぐため、「exact increment が精密に局在した」とは言いません。

### P2: North–Tropical joint response は同じ islands / same-species support でも残る

[PR #227](https://github.com/zuizui0223/island/pull/227) は、H2 の formal comparison を `northern_midlatitude` vs `tropical` に固定し、support mismatch を直接攻撃しました。

Primary direct-only × native-nonendemic common-island audit:

- **348 common islands / 78 spatial blocks**
- joint vector difference **p = 0.0009473**
- northern vector `(accessibility, assurance) = (0.02544, 0.03743)`
- tropical vector `(-0.10394, 0.17466)`

同じ853 direct-only co-observed speciesだけで両axisを再構築しても、280 islandsで joint difference **p = 0.00517**。したがって「axisごとに別のspeciesが入ったから差が出た」という説明だけでは消えません。

ただし determinant = 0.007458 の paired-block 95% CI は **[-0.003193, 0.015991]**、angle 67.1°の intervalも広く、**強い vector non-collinearity は未確立**です。また Palearctic–Neotropical という別layerの直接比較は p=0.078–0.396 で非支持です。

### P3: observation bias をjointに動かしても Palearctic accessibility は残る

[PR #228](https://github.com/zuizui0223/island/pull/228) は、trait-resolution MNAR と distance-dependent flora-list completeness / state-dependent species recording を同時に動かす **1,575 surfaces / evidence scope** を prospectively frozen contract 下で開きました。

Primary direct-only × native-nonendemicでは、

- formal North–Tropical vector: **1541/1575 = 97.8%** robust
- Palearctic accessibility: **1575/1575** robust
- tropical accessibility: **1269/1575 = 80.6%** robust

でした。

さらに48 deterministic partial-identification cornersで、Palearctic accessibility の estimate envelope は direct-onlyで **[0.0392, 0.1428]** と正符号を保持します。一方、tropical accessibility は **[-0.0942, 0.0391]** と0を跨ぎます。formal North–Tropical vectorも finite gridでは強いものの、全deterministic cornersで formal support が identified ではありません。

よって Chapter 1 の observation boundary は三段に分かれます。

1. **observation-robust core:** Palearctic accessibility
2. **finite-domain robust / partially identified:** formal North–Tropical vector difference
3. **observation-fragile:** tropical accessibility

これは「arbitrary missingness を解決した」結果ではなく、あくまで predeclared finite assumption domain の中での分類です。

### draft PR #229: all-observed flora の強いglobal signalは native assembly に移らない

今日さらに大事なのが、まだ **draft / open** の [PR #229](https://github.com/zuizui0223/island/pull/229) です。これは frozen v11 を置き換えない additive exploration です。

全 trait-evaluable observed flora を使う beta-binomial six-atomic vector では、

- all evidence: **3,626 islands / 187 blocks, p = 0.000763**
- direct H/M: **3,569 islands / 187 blocks, p = 0.004502**

で broad North–Tropical response difference が出ます。matched grouped-binomialでも p=0.001385 / 0.004501 なので、Validated-Low や model-form だけの artifact ではありません。

ところが source-backed native にすると p=0.2491 / 0.3018、native non-endemic は p=0.05097 / 0.2079。さらに WCVPで **513,320 rows / 2,372 islands** まで regional-native-compatible flora を大きく拡張しても、North–Tropical test は **p=0.07954 / 0.17472** で支持されません。

同じ375 status-supported islands上でも all-observed は p=0.0005607 / 0.0003959 なのに native-only は p=0.2491 / 0.3018。したがって単なる island 数の損失ではありません。

**解釈:** 全球の contemporary observed floras には明瞭な context-dependent floral/reproductive composition difference がある。しかし、それをそのまま **native island assembly / colonisation filtering / in-situ adaptation** と呼ぶことはできません。native assembly として最も守れるのは、むしろ frozen v11 の narrower, lineage-structured core です。

## 2. azami — 「among taxa の方が統合が強い」は RV の n 差だけでは消えなかった

[PR #110](https://github.com/zuizui0223/azami/pull/110) は、1,734 within-taxon rows と42 taxon mediansを ordinary RV で比べると finite-sample baseline が違う、という submission-critical threat を直接検証しました。これは**post-hoc estimator-validity sensitivity**で、prospective/preregistered testではありません。

元の raw common-cohort result は median RV within = **0.0022379**、among = **0.0432123**、33/36 relationsがamongで強い、でした。

primary equal-n sensitivityでは、within側も各taxon 1 observationにして42 rowsへ揃え、**1,000 replicates**を実行しました。

- matched within median RV: **0.023897** [0.012861, 0.041329]
- among-minus-within median RV: **+0.019316**, 95% **[+0.001884, +0.030352]**
- difference positive: **98.3%** of replicates
- relations stronger among taxa: median **23/36**, 95% **18–27**
- majority (>18/36) stronger among taxa: **97.3%**

したがって、**visible-phenotype integration is stronger overall among taxa** という質的結論は残ります。ただし raw **33/36** は estimator-robust headline ではなく、typical equal-n count は23/36まで下がるため、主張を狭める必要があります。

さらに permutation-null centring（499 permutations/pair/scale）でも median among-minus-within = **+0.008019**、19/36 が among で強い。coordinate-standardization sensitivityでも 34/36、matrix alignment **rho=0.40849, QAP P=0.0067**、module cohesion は within **P=0.0010** / among **P=0.0369** と残りました。

**生態学的意味:** 種内写真変異と種間形態差で visible phenotype の共分散構造が同じ強さではない、という scale contrast は finite-sample RV baseline だけでは説明し切れません。ただし、これは evolution が integration を増やすこと、genetic/developmental modularity、plasticity、adaptation を直接示しません。

## 3. EGWEE — 5つ目の独立clusterは「generalityを救済」せず、Serapias依存をむしろ確定した

新しい ML020 は Aizen–Feinsinger 1994 Chaco programme。small forest fragment (<1 ha) vs continuous forest を、3 source-explicit species × 4 sites × 2 conditions から回収し、programme全体を**独立cluster 1つ**として扱っています。

3種とも pollen-tube support と fruit set は fragmentation 側で低い方向でしたが、I−F の within-species differences はいずれも非有意です。

- *Atamisquea emarginata*: I g=−0.713, F g=−1.005, I−F p=0.798
- *Cercidium australe*: I g=−0.637, F g=−1.139, p=0.618
- *Prosopis nigra*: I g=−0.481, F g=−1.135, p=0.557
- programme-level Bonferroni p = **1.0**

それでも legitimate same-effect-family cluster なので denominator に追加され、5-cluster Fisherは **χ²(10)=22.6477, p=0.012124**。full corpus は complete layer exchangeability をなお棄却します。

しかし、Serapiasを外すと **p=0.181944** で非棄却。4-cluster時の omit-Serapias p=0.07777 から、むしろ generality は救済されませんでした。したがって5系目を追加したことの最大の情報は、**signal breadth は増えたが Serapias-independent robustness は成立しない**ことです。

covariance auditも境界をさらに狭めます。

- frozen paired covariance: full p=**0.01212**
- off-diagonal covarianceを0にする sensitivity: **p=0.03860**
- marginal variancesだけから Cauchy–Schwarz covariance-free bound: **p=0.28061**

つまり signal は「特定の非ゼロ covariance proxy を置いたせい」だけではありませんが、**paired dependence informationを完全に捨てても保証できる結論ではない**。どの dependence regimeでも omit-Serapias は非支持です。

**生態学的意味:** fragmentation effect は connectivity/reproductive layersで常に同じ強さではない可能性があるが、現在の cross-system state-separation claim はまだ一つの influential systemに依存します。ここから significance を救うために第6系を探すのではなく、次の拡張をするなら system coverage を事前に定義すべきです。

## 4. ODSP — directional alternative を事前に宣言できると weak-signal power をかなり回収できる

これは ecological endpoint ではなく、方法性能の新結果です。[paired directional power receipt](https://github.com/zuizui0223/odsp/blob/main/PAIRED_DIRECTIONAL_POWER_COMPARISON_RECEIPT.json) は同じ simulated worlds / 同じ shared-block bootstrap seed で two-sided と one-sided を prospectively比較しました。各scenario **1,000 simulations**。

- strong-full, 20 blocks: exact recovery **0.993 → 0.995**
- strong-full, 50 blocks: **1.000 → 1.000**
- weak-full, 20 blocks: **0.252 → 0.413**（**+0.161**）
- coarse-null normal: **1.000 → 1.000**, overreach 0
- coarse-adverse normal: **1.000 → 1.000**, overreach 0
- coarse-null t3 heavy-tail: **0.825 → 0.889**（**+0.064**）, overreach 0

same-world paired countでは **227 ceiling advances / 0 regressions**。したがって、`positive transfer` という directional alternative を事前に宣言できる場合、tested designでは false promotion を増やさず underreach の一部を戻せました。

ただしこれは simulation / method qualificationであり、historical empirical endpointsを再分類していません。shared-block exchangeabilityを仮定し、upstream refit uncertaintyも含みません。また1 shared blockしかない入力は今日の修正で fail-closed になっています。

## 全リポ横断 — 昨日より何が一段進んだか

昨日は「positive claim の applicability domain と failure mode を同時に測る」という方向まで来ました。

今日はさらに、**同じ pattern を別の scientific object に読み替えないための境界**が具体化しました。

- `island`: **contemporary observed-flora difference ≠ native assembly**。native assemblyとして守れる部分は narrower / lineage-structured。
- `azami`: **raw RV magnitude/count ≠ estimator-robust scale contrast**。33/36は弱まるが、overall among-taxon strengtheningは残る。
- `egwee`: **full-corpus rejection ≠ system-independent generality**。5系まで増えても Serapias omissionで崩れる。
- `odsp`: **directional methodのpower gain ≠ empirical promotion**。method simulationで良くても既存 endpointは書き換えない。

つまり研究全体は、単に「robustness check をたくさんやる」段階ではなく、

> **どの観測集合・estimator・独立系・assumption domainに対して、どの scientific noun（assembly / integration / generality / transfer）を使ってよいかを決める段階**

に進んでいます。

これは論文上かなり強いです。正の結果だけを積み上げるより、**どの読み替えが禁止されるかまで定量的に示せる**ため、claim の意味がはっきりします。
