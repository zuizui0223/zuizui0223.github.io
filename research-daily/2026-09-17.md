## 1. island — 全球では isolation と pollen limitation が正に関連する

今日いちばん大きい新規 empirical positive です。Chapter 1 H5 の full-global GloPL route は、outcome を見る前に sampling frame と分析を凍結した上で **2,969 georeferenced experiments / 1,248 sites / 919 publications** を扱いました。内訳は mainland-zero-distance 988 sites、offshore 260 sitesを含みます。

canonical result は、major continental landmass からの標準化距離に対する pollen limitation の傾きが

- **slope = +0.07937**
- **SE = 0.03773**
- two-sided **p = 0.03543**
- predeclared one-sided positive **p = 0.01772**

で、repository classification は `global_pollen_limitation_gradient_supported_context_specificity_not_established` です。結果 lock は [`chapter1_h5_glopl_global_distance_result_lock.json`](https://github.com/zuizui0223/island/blob/main/config/chapter1_h5_glopl_global_distance_result_lock.json)、integration は [`chapter1_h5_pollination_global_integration_v5_20260916.md`](https://github.com/zuizui0223/island/blob/main/docs/chapter1_h5_pollination_global_integration_v5_20260916.md) に固定されています。

### 何の生態学的問いに答えるか

**大陸から遠い場所ほど、植物の繁殖が花粉不足によって制限されやすいか。**

少なくともこの全球 experimental synthesis では、答えは **yes と整合**します。地理的隔離は、単なる植物相の構成差だけでなく、実験的に測られた pollen limitation の増加とも結びついています。

### 機構としてどこまで言えるか

ここはかなり重要です。これは

- pollinator abundance の直接低下を測ったわけではない
- visitation decline を直接測ったわけではない
- island-only causal contrast ではない
- Chapter 1 の地域別 plant response を mediation したとは言えない

という ceiling を保ちます。

post-hoc shape audit では offshore-only slope **+0.23545, p=0.005865**、within-offshore slope **+0.19983, p=0.01110** と正方向が続きますが、これは post-hoc なので parent promotion を強くする材料には使いません。

### 論文化すると何を主張できるか

> **Pollen limitation increases with geographic isolation in a large global experimental synthesis, but this broad service gradient does not identify the context-specific plant-response mechanism of island floral assembly.**

ここまでならかなり強いです。

## 2. island — しかし pollen limitation は North–Tropical branching の共通上流機構ではなかった

同じ H5 programme の価値は、positive global slopeを得たあとに**mechanism rescue を続けなかった**ことです。

North slope は **+0.06170**、Tropical−North interaction は **+0.14300**。事前予測は「Tropical では isolation slope が弱い」方向でしたが、interaction point estimate はむしろ逆です。predeclared negative-interaction test は **p=0.9119** で、Chapter 1 H2 の North–Tropical branching を pollination-service gradient だけで説明する橋は支持されませんでした。

さらに functional buffering を two route で検証しました。

**Route A: reproductive assurance** では、exact species overlap 642。self compatibility、mating system、autonomous selfing の frozen family rule は **0/3 supported**。autonomous selfing interaction は −0.0736 ですが one-sided buffering **p=0.1543**、self compatibility は予測と逆方向、mating system は support不足で non-evaluable でした。

**Route B: floral architecture** は exact overlap 624 species。generalized form、actinomorphic symmetry、shallow/open tube の frozen family ruleも **0/3 supported**。generalized-form interactionは −0.06674, **p=0.2441** で sensitivity により符号が反転、actinomorphic interactionは予測と逆、tube contrastは support不足でした。

したがって、全球で pollen limitation gradient があることと、**その gradient が Chapter 1 の trait branching を作る**ことは別です。

### 昨日より一段進んだ点

昨日は `observed-flora difference ≠ native assembly` を分けました。今日はさらに

**global service limitation ≠ context-specific plant branching mechanism**

まで分けられました。これは Chapter 1 を弱くするより、むしろ `where / whether / lineage assembly` と `mechanism` を別の evidence layer にする強い整理です。

## 3. island — all-observed contemporary flora の regional structure は merge 後も genus residualization で残る

昨日は draft だった all-observed route が [PR #229](https://github.com/zuizui0223/island/pull/229) で main に入りました。ただし native assembly と混同しない two-panel design です。

all-observed contemporary flora の North–Tropical comparison は beta-binomialで

- all-analysis: **3,626 islands / 187 blocks, p=0.0007633**
- Direct H/M: **3,569 / 187, p=0.004502**

と明瞭です。

さらに source-free leave-one-out taxonomic residualization 後も、

- after family: **p=0.01043 all / 0.02497 direct**
- after genus: **p=0.01150 all / 0.004593 direct**

で差が残り、`generalized_form` と `self_compatibility` が明瞭な retained components です。

これは「全観測植物相の regional composition difference は単なる genus turnover だけでは消えない」ことを支持します。しかし **within-lineage evolution の証明ではありません**。一方、defended native panel の Palearctic response は observed→family-adjusted→source-matched-genus-adjusted **4/4→4/4→0/4**、genus attenuation **78.8–85.9%** のままです。

この組合せから、現在の全球植物相に見える広い差と、native assembly として守れる lineage-structured signal は別の object として論文化するのが最も安全です。

## 4. 新規 IWE — Corydalis で timing mismatch と seed set の直接 Tier-A evidence を最初に回収

新規リポ [`iwe`](https://github.com/zuizui0223/iwe) は **Interaction Window Ecology**。植物–動物相互作用の phenological synchrony が植物繁殖へ与える効果を、mutualist / antagonist / mixed pollinating seed predator の間で比較する実証メタ解析です。Tier C の occurrence-derived overlap を primary meta へ入れないこと、study dependence を保持することまで最初から frozen contract に入っています。

最初の real Tier-A extraction は Kudo & Ida 2013 の *Corydalis ambigua* × overwintered bumblebee queens 長期データです。source tableから、各 site×year の flowering onset、first bumblebee detection、signed mismatch、natural seed set を直接再構築しました。

3地点の mismatch vs natural seed set の Pearson r は、

| Site | n years | r(mismatch, seed set) | oriented Fisher z |
|---|---:|---:|---:|
| NFP | 13 | **−0.6823** | **+0.8335** |
| TOEF | 9 | **−0.9042** | **+1.4945** |
| JOZ | 7 | **−0.8185** | **+1.1522** |

です。IWEのorientationでは positive = より小さい mismatch / より高い synchrony が高い reproductive performance と結びつく、なので**3/3 sites が同方向**です。

ただし3地点は同一長期programmeで `DEP_IWE001_LONGTERM` を共有し、3 independent studies として扱いません。またこれは source-transparent Pearson reconstruction で、原論文の fitted regression coefficientそのものではありません。

### 何の生態学的問いに答えるか

少なくともこの一系では、**plant flowering と bumblebee activity の時間的不一致が大きい年ほど seed set が低いか**に対して、3地点すべてで強い負の association が回収されました。

### 何をまだ言えないか

- synchronyの causal effect
- mutualist一般の平均効果
- antagonistとの moderation
- first bee detection と full activity distribution の同一性
- IWE H1/H2 の meta-analytic conclusion

はまだ開きません。

論文化への一歩としては、これは **first direct effect-unit audit が成立した**段階です。次は同じ Corydalis datasetの重複publicationを独立扱いせず、全く別の interaction systemを追加することが重要です。

## 全リポ横断で昨日より何が一段進んだか

昨日の中心は「positive result にどの scientific noun を付けてよいか」でした。

今日はそれが、実際の ecology の一連の問いでさらに具体化しました。

1. **isolation と pollen limitation は全球で関連する** — supported。
2. **その service gradient が North–Tropical plant branching を作る** — not supported。
3. **reproductive assurance / floral architecture がその gradient をbufferする** — frozen testsでは not supported / unavailable。
4. **特定 plant–pollinator system で phenological mismatch が reproductive outputと結びつく** — IWE001で supported。
5. **それが interaction typeを跨ぐ一般則か** — IWEではまだ未評価。

つまり、同じ「pollination / reproduction」の物語でも、

**geographic service gradient → system-specific timing effect → trait buffering → macroevolutionary/assembly response**

は一つの証拠でまとめてはいけません。各edgeを別のestimandとして閉じる方が、全体の因果ストーリーはむしろ強くなります。
