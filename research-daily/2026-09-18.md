## 1. island — flower colour は selfing の代理ではなく、独立した display module として残った

[PR #233](https://github.com/zuizui0223/island/pull/233) は、最終 **106,295-species / 3-axis trait snapshot** の花色を `plain_colour` に潰さず、`white / red_pink / yellow_orange / blue_purple / green_brown_inconspicuous` の5つの reported state として保持して解析しました。multistate species も残し、各色を `selfing_core` の調整前後で解析し、さらに5色全体の joint Wald test を行っています。

`selfing_core` 調整後も、Northern mid-latitude では `red_pink` が **q=0.0111（all）/ 0.0312（direct）** で減少し、five-colour vector 自体も両 evidence scope で支持されました。Tropical では all-analysis で `white↑ / green_brown_inconspicuous↑ / blue_purple↓`、direct-only で `yellow_orange↑ / green_brown_inconspicuous↑`。Southern extratropical でも joint five-colour vector が両scopeで支持され、direct-onlyでは `white↑` が強く残りました。一方、Northern high latitude では five-colour vector 自体が支持されませんでした。

### colour–architecture coupling はさらに context dependent

色の周辺頻度そのものと `selfing_core` を条件づけても、Northern high latitude では、

- `blue_purple × butterfly-associated form↓`: **q=0.00144 all / 0.000681 direct**
- `blue_purple × intermediate/deep large-bee-associated tube↓`: **q=0.00144 all / 0.000266 direct**
- direct-only の `yellow_orange × butterfly-associated form↓`: **q=0.0274**

が残りました。

Tropical direct evidence では `yellow_orange × deep butterfly-associated tube↑` が **q=0.0355**。Southern extratropical の all-analysis では `yellow_orange × bird-associated form↓` と `yellow_orange × intermediate/deep tube↑` がどちらも **q=0.0129** でしたが、direct-onlyではFDR後に残りません。Northern mid-latitude では raw `red_pink↓` は頑健なのに、named colour–architecture coupling はFDR後に残りませんでした。

### 何の生態学的問いに答えるか

**島嶼隔離に伴う花色変化は、単に reproductive assurance / selfing の変化を言い換えただけか。**

今回の答えは **no と整合**します。少なくとも final trait snapshot 上では、raw colour composition に selfing-adjusted structure が残り、さらに一部の地域では同じ色がどの floral architecture と組み合わされるかまで変化します。

### どんな機構として解釈できるか

安全な解釈は、isolation に伴って **pollinator-facing floral display composition が再編され、その再編の仕方が ecological context によって異なる**、までです。

色から realized pollinator identity を逆推定してはいけません。今回の結果は attraction intensity、UV contrast、visitation、historical pollinator loss、causal mediation を直接測っていません。特に「青紫＝蜂」「赤＝鳥」のような one-colour-one-pollinator 解釈は、この coupling result 自体がむしろ拒んでいます。

### 論文化すると

PR #234 では Chapter 1 v13 の中央仮説が、凍結済み H1 の6 atomic traitsを変えず、

**reproductive assurance / floral accessibility-generalization / pollinator-facing display reorganization**

という **3つの partially separable phenotype modules** に整理されました。raw colour は7番目の confirmatory H1 trait に昇格せず、secondary phenotype family のままです。

これは昨日の GloPL 結果を再カウントしたものではなく、**plant-side response の内部構造を一段細かくした新しい empirical extension**です。

## 2. BITA — aggregate interaction から mechanism を「点推定せずに」一段だけ絞れた

[PR #223](https://github.com/zuizui0223/bita/pull/223) は、Kessler system の registered aggregate interaction floor

**Δ_AD W ≥ +0.1710239**

を、BITA の mechanism identified set へ伝播しました。

mechanism decomposition を

`Δ_AD W = ρ_Δ − ι_Δ − κ_Δ`

と置くと、独立に正当化される制約 **`κ_Δ ≥ 0`** の下では、

`ρ_Δ − ι_Δ = Δ_AD W + κ_Δ ≥ +0.1710239`

となります。つまり antagonist-relief minus pollinator-interference の **conditional biotic-balance lower bound が +0.1710239** と数値化されました。

### 何が新しく支持されたか

ここで支持されたのは「individual mechanism channel の effect size」ではありません。

新しく得たものは、

> **aggregate interaction が正であり、さらに `κ_Δ ≥ 0` という生物学的制約を置くなら、二つの主要biotic channelの差にも正の下限を置ける**

という **conditional partial-identification result** です。

`ρ_Δ`、`ι_Δ`、full channel allocation は依然 **NOT_POINT_IDENTIFIED**。自然界でこの mechanism がどれくらい普遍的かも推定していません。

### 生態学的意味

「総 interaction が正だから pollinator effect と antagonist effect の内訳も分かった」と飛躍するのではなく、**測れていない channel を明示的に残したまま、許される mechanism space を狭める**ことができました。

論文では、

> *A positive aggregate interaction can impose a non-zero lower bound on a biologically interpretable channel balance under an explicit sign restriction, while individual mechanisms remain unidentified.*

までが強いです。

## 3. SCH — 4つの conflict design があっても、今は pooled mean を出してはいけない

[SCH PR #42](https://github.com/zuizui0223/sch/pull/42) は、strict same-coordinate conflict designs を machine-readable compatibility matrix にしました。

結果は非常に明瞭です。

| quantity | current state |
|---|---:|
| registered designs | **4** |
| exact component coefficients | **2** |
| valid contrast variances/covariances | **0** |
| currently poolable designs | **0** |
| random-effects gate | **FAIL_CLOSED** |

exact numeric がある2系では、within-study contrast は、

- *Dalechampia scandens*: pollinator **+0.6938** vs seed-predator **−0.3093** → conflict contrast **1.0031**
- *Silene stellata*: male function **+0.645** vs female function **−0.267** → contrast **0.912**

です。

ただし Dalechampia は component estimate 間の covariance が報告されず valid contrast variance を作れません。Silene はcomponent uncertainty自体が不足しています。Fragaria と Gymnadenia は exact source table の numeric recovery が未完で、値を図から推測して埋めることも禁止しています。

### 何の生態学的問いに答えるか

**複数研究で opposing selection が見えるなら、その大きさを一つの平均 conflict effect としてまとめてよいか。**

現時点の答えは **no** です。

これは「conflict がない」という negative ではありません。むしろ **within-study evidence と cross-study pooled estimand は別物**だと明示した結果です。

### 論文化すると

`POOLED_CONFLICT_EFFECT = NOT_ESTIMATED`、`NATURAL_PREVALENCE = NOT_ESTIMATED` を維持したまま、

> *Strict same-coordinate conflict examples exist, but the present evidence base lacks the variance/covariance and estimand compatibility required for a valid pooled effect.*

と言えます。
