## 1. TTF — 「within-species signal はあるが cross-species transfer は検出されない」を初めて fresh genetic endpoint で閉じた

[`TTF` PR #51](https://github.com/zuizui0223/TTF/pull/51) は、これまで sealed だった phylogatR Phase-4 を exact source archive から再構築して一度だけ開封しました。source archive は **274,988,692 bytes**、Phase-1 は response-blind に **250 species** を再構築し、Phase-4 authorization 後の survivor は **211 species** です。

primary `place_beyond_ibd` は、

- statistic = **0.0325655**
- profiled-private p = **0.73926**
- decision = **not positive**

でした。一方、事前に synthetic qualification を通した within-species self diagnostic は、

- statistic = **-0.226098**
- p = **0.008991**
- positive = **true**

でした。receipt の正式 decision は `LINEAGE_CONDITIONED_SPATIAL_STRUCTURE_WITHIN_TESTED_DOMAIN` です。

### 何の生態学的問いに答えるか

**ある種内で検出できる mitochondrial spatial structure は、同じ frozen rule で別種へ transport できる一般的な geographic signal か。**

今回の答えは、tested domain では **within-species detectability はあるが cross-species transfer は検出されない**、です。これは「遺伝構造がない」という結果ではなく、逆に self diagnostic が positive なので、signal absence を単純な power不足に還元しにくい点が重要です。

### 生態・進化解釈

安全な解釈は、mitochondrial spatial differentiation の mapping が **lineage-conditioned** である可能性です。共有された geographic distance rule だけでは十分でなく、種ごとの dispersal history、barrier history、demography、range geometryなどが関与し得ます。

ただし、特定の歴史要因を同定したわけでも、「どの種にも transferしない」と証明したわけでもありません。

### 論文化すると

> *A prospectively frozen fresh genetic test detected within-species spatial structure but did not detect cross-species transfer of post-IBD mitochondrial differentiation within the tested domain.*

までが強いです。

## 2. PAYOFF-B — universal speed optimum は崩れ、phase-error correction が実データで立ち上がった

[`PAYOFF` PR #144](https://github.com/zuizui0223/payoff/pull/144) は open draft なので、active Theoretical Ecology theorem paperとは分離して扱います。

まず broad bird reanalysis は **5,816 species×year×cell observations / 55 migratory species / 15 years**。raw arrival–green-up mismatch は universal order-one optimumを支持しませんでした。species×cell phase centering 後の flexible minima は roughly **1.04–1.40** に移動しますが shallow / uncertain で、species-level heterogeneityも大きい。つまり、自然界に共通の `movement speed / environmental-wave speed` 定数を置く読みは支持されません。

一方、independent mule-deer system は **152 animal-years / 72 individuals / 8 years** で、

`log(u_macro) = alpha + kappa * start_phase_error`

を当てると、

- `kappa` = **0.01830 / day**
- clustered SE = **0.001223**
- p = **1.21e-50**
- positive slope = **8/8 years**

でした。1日遅れるごとに relative movement speed が約 **1.85%**高い方向です。stopover duration も **-0.492 d / +1 d phase error**、cluster p = **6.07e-37**。absolute phase error は migration start から end まで **10.79 ± 1.41 d** 減少し、p = **2.28e-14**。

controller summary は、

- stable phase `E*` = **8.46 d**
- green-wave speed = **5.61 km/d**
- e-folding correction distance ≈ **307 km**
- half-error distance ≈ **213 km**

です。

### 何の生態学的問いに答えるか

**移動個体は一つの普遍的 speed ratio を目指すのか、それとも resource-wave からの phase error に応じて移動行動を調整するのか。**

現時点では後者がはるかにデータと整合します。

### 生態学的機構

これは observational closed-loop signature です。遅れが大きい個体ほど移動速度を上げ、stopoverを短縮し、結果として phase error が圧縮される。しかも stable phase は0ではありません。つまり「資源ピークと完全一致」ではなく、**system-specific な非ゼロ位相を維持する feedback controller**として読む方が自然です。

ただし causal behavioral control、evolutionary optimum、lifetime fitness optimumは未証明です。

### 論文化すると

> *Movement–phenology matching is better described as feedback toward a system-specific phase offset than as convergence on a universal movement/environment speed ratio.*

が現在の強い主張です。

## 3. island — isolation-associated plant response が「現在の pollen limitation を下げる」方向へ接続する post-hoc bridge

[`island` PR #237](https://github.com/zuizui0223/island/pull/237) は Chapter 1 v14 を H1–H4 に並べ直しました。H1 の7-response joint syndrome は4 geographic strata × both evidence scopesで支持され、all-analysis BH q は northern mid **2.36e-6**、northern high **2.61e-6**、tropical **3.78e-7**、southern extratropical **1.60e-12**。ただしこの部分は主に既存 v13結果の再構成です。

今日新しく効くのは H4 の literal H2-score bridgeです。Direct-only H2 species scoresを exact-species GloPL data に結ぶと、

**selfing_core**
- **455 species / 409 publications / 734 cells**
- beta = **-0.29706**
- p = **0.00411**

**generalized_accessible**
- **143 species / 143 publications / 259 cells**
- beta = **-0.29601**
- p = **0.0222**

でした。atomic reconstruction sensitivityも同方向で、reproductive assurance beta **-0.31255, p=.00222**、H2-weighted accessibility **-0.32932, p=.00515**、equal-weight accessibility **-0.32509, p=.00636**です。

### 何の生態学的問いに答えるか

**isolation に伴って増える reproductive assurance / accessible floral architecture は、現在の pollen limitation とどう対応するか。**

post-hoc discovery では、両方とも **higher plant-response score ↔ lower current pollen limitation** です。単純な `isolation → pollen limitation → plant response` の一方向 mediation より、**植物側の assurance / accessibility が service limitation を部分的にbufferする**という読みと整合します。

### ただし最重要の ceiling

この H4 は **post-hoc discovery** です。prospective post-2015 wild validation は frozen gateの **30 species / 10 publications** に対して各family **9 matched species** しかなく、outcome unblinding前に `NOT_EVALUABLE` で停止しました。PolLimCrop も別domainのsupplementary transportで、wild support failureを救済しません。

したがって論文化すると、

> *Isolation-associated selfing/accessibility scores are negatively associated with current pollen limitation in a post-hoc exact-species bridge, consistent with functional buffering but not yet prospectively validated.*

までです。

## 4. FCP / disttrait — external transport は通ったが、モデル選択は estimand 次第

[`FCP` PR #46](https://github.com/zuizui0223/fcp/pull/46) は generic `disttrait` spatial layerを historical San Francisco street-tree inventoryへtransportしました。outcome-blind deterministic selectionは **20 taxon labels × 80 trees = 1,600 observations**、traitは `log(DBH)`。

species-conditioned resultは、

- mean within-taxon spatial rho = **0.0921946**
- matched-null p = **0.01**

で positive geographic organizationを検出しました。一方、taxon-level `SD(log DBH)` と spatial rho の関連は **rho=-0.186466, p=.83** で非支持。naive pooled all-pairs rhoは0.02783でも nominal pは極端に小さいですが、巨大なpair数を独立replicateと見なせないため superiority evidenceにはしていません。

これは urban-tree ecology の因果結果ではなく、**花色に依存しない continuous-trait empirical transport**です。

さらに [`PR #48`](https://github.com/zuizui0223/fcp/pull/48) では species-specific signed slopes を random-effects summaryに載せましたが、small n + 50% MCAR で通常の analytic calibration が anti-conservativeでした。

- analytic combined omnibus max null rejection = **0.30**
- matched within-species permutation calibration後 = **0.05**

effect=0.4 / 50% direction reversalでは、

- common signed slope detection = **0.025–0.05**
- direction-invariant distance-dissimilarity = **0.40–0.90**
- calibrated slope-heterogeneity = **0.75–1.00**
- calibrated omnibus = **0.525–1.00**

です。

この方法論結果の核心は、**shared direction を問うモデルと、speciesごとに方向が違っても spatial organization があるかを問うモデルは、優劣ではなく別estimand**ということです。

## 5. CHUN — flower-colour memory は relative time とともに減衰するが、universal resolution はない

[`CHUN` PR #299](https://github.com/zuizui0223/chun/pull/299) は frozen Flower-clades-51 を relative evolutionary time で再解析しました。time axis は各clade内の patristic distanceをcrown heightで規格化したもので、absolute Maではありません。

fine visible colour の eligible **32 clades** では、

- negative persistence slope = **23/32**
- median slope = **-0.1897**
- one-sided Wilcoxon p = **0.00120**
- sign-test p = **0.0100**
- bootstrap 95% interval = **[-0.373, -0.090]**
- positive integrated excess-retention area = **23/32**, Wilcoxon p = **0.00467**

でした。つまり exact visible colour state は近い分岐で共有されやすく、relative divergenceが深くなるほどそのmemoryが一般に減衰します。

一方 common 28-clade frameで persistence-area winner は coarse **13** / intermediate **10** / fine **5**、pairwise testsは全て p>0.05。**一つの普遍的 optimal resolution はありません。**

さらに、この derived temporal result は既存AUCと同じ state-sharing / phylogenetic-distance情報を再利用し、fine slope vs AUC は rho **-0.845, p=1.60e-8**。したがって **新しい temporal interpretationであって独立replicationではありません**。

追加の prospective/retrospective auditsも universal shortcutを支持しませんでした。flower–fruit memory tradeoffは予測方向を支持せず、stress-associated colour memoryも directional but non-significant FAIL。ここからの論文主張は、

> *Flower-colour states carry recent phylogenetic memory that decays with relative divergence, but the resolution that best preserves that memory is clade-dependent.*

程度が安全です。

## 全リポ横断：昨日より何が一段進んだか

昨日は、**一つの effect / syndrome / mechanism に潰さず、どこまで同定・統合できるかを結果にする**ところまで来ました。

今日はその考え方が、実データでさらに一段深くなりました。

**TTF**は、within-species spatial structure があることと、そのmappingが species間でtransportすることを切り分けました。  
**PAYOFF-B**は、広域なuniversal optimumと、個体がphase errorを補正するsystem-specific feedbackを切り分けました。  
**CHUN**は、flower-colour memoryの存在と、そのmemoryを最大化するuniversal resolutionの存在を切り分けました。  
**FCP**は、shared directional slopeとdirection-invariant spatial organizationを切り分けました。  
**island**は、isolation-associated plant syndromeと、それがpollen limitationをbufferしているというfunctional bridgeを切り分け、後者をpost-hocに留めました。

したがって今日の横断結論は、

> **「構造がある」→「他の系にも同じ形で移る」→「普遍法則である」という3段階を、自動的につながない研究体系になった。**

です。

これは否定的になったのではありません。むしろ、**within-system organization はどこで強く再現し、cross-system transfer / universal scaling はどこで壊れるか**を同じ研究群の中で直接測れるようになったことが大きな前進です。

## 今日の最重要3点

1. **TTF — fresh genetic endpoint:** within-species spatial structureは qualified diagnosticで支持（p=0.00899）されたが、primary cross-species transferは非支持（p=0.739）。**lineage-conditioned spatial structure**という境界を一度きりのfrozen testで閉じました。
2. **PAYOFF-B — movement–phenology:** 55-species bird dataは universal speed optimumを支持しない一方、mule deer では `kappa=0.01830/day`、8/8 years positive、phase-error reduction **10.79±1.41 d**。**fixed optimum → feedback phase locking**へ理論と実証の主線が変わりました。
3. **island H4 — buffering candidate:** `selfing_core beta=-0.297, p=.0041`、`generalized_accessible beta=-0.296, p=.0222` と current pollen limitation の負関連を回収。ただし prospective wild validationはsupport不足で未開封。**機能的bufferingは有望だが、まだpost-hoc**です。

## 次に回収すべき解析 / 検証

**TTF**は同じ phylogatR endpointをretuneしないこと。すでに独立confirmatory panelを別系統でfreezeしているので、次はその disjoint panelで **lineage-conditioned boundaryが再現するか**を一度だけ判定するのが最大情報利得です。

**PAYOFF-B**は mule-deer を唯一のdirect controller systemのままにしないこと。barnacle goose / wigeon の raw individual-stopover dataで compatible `kappa / E* / correction distance` を回収し、**少なくとも3 independent Tier A/B systems**になるまで pooled controller meta-analysisを開かない。

**island**は H4 post-hoc resultを追加subsetで救済しない。support-complete な独立wild datasetか、`izu-core` の same-tagged-plant `visitor -> deposition/effectiveness -> dependency -> mature seed` chainで buffering / service mediationを直接測る方が強いです。

**CHUN**は relative-time memoryを prospective ecological moderator huntへ広げず、独立datasetで temporal-shape ruleを先にfreezeして検証する。absolute time claimをするなら calibrated phylogenyが必要です。

**FCP / disttrait**は、external transportが一系通ったので、次は MNAR observation と nonlinear/multivariate trait geometry。common-slope / random-slope / distance-dissimilarityの比較は「どれが勝つか」ではなく、事前にscientific estimandを固定してから選ぶべきです。

**BITA / SCH / BALANCE**は、例数を増やすだけでなく、consumer role、same-coordinate geometry、dependency group、variance/covarianceを揃えた numerator / denominator を作ることが次です。
