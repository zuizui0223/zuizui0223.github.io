## 1. BITA — access mismatch が robbery route を予測する独立 community-scale support

`BITA` の all-Ecuador extension は **18 sites / 1,378 pair-site rows** を使い、花筒長が鳥の嘴長を上回る `mismatch > 0` を barrier と定義しています。barrier pair-sites は **888**、accessible は **490**。

- mean robbery rate: barrier **0.30698** vs accessible **0.08139**
- difference = **+0.22560**
- permutation **p = 0.0001**
- continuous mismatch vs robbery: Spearman **rho = 0.41826**, permutation **p = 0.0001**
- within-site difference: **15/17 sites positive**
- sign-test **p = 0.00235**
- site-stratified permutation **p = 0.0001**

追跡可能な frozen result: [`aubert2026_zenodo_extension.json`](https://github.com/zuizui0223/bita/blob/d8376ff7ef6bfec4d2f268074c24d67f9be686db/empirical/floral_defence_selectivity/results/aubert2026_zenodo_extension.json)。

### 生態学的問い

**花の defence/access geometry は antagonist abundance だけでなく、訪花者が legitimate access から robbery へどの経路を取るかを変えるか。**

この結果は Yes と整合します。花筒と嘴の mismatch が大きい組合せほど robbery が増え、siteごとの比較でも同じ方向が広く残ります。

### 機構解釈と論文 claim

安全な機構語は **access routing** です。形態的な access barrier が interaction route を変更するという community-scale association は支持されます。ただし fitness benefit、causal floral defence、trait evolution は未同定です。

> *Morphological access mismatch is associated with a shift toward nectar robbery across an independent 18-site community dataset.*

までが強いです。

## 2. CHUN — 「memory の量」と「memory が見える解像度」は別軸

28 completed clades の coarse / intermediate / fine AUC profile を固定座標へ分解すると、between-clade variance は、

- memory amplitude **90.65%**（clade-bootstrap 95% **79.1–96.2%**）
- coarse↔fine scale tilt **6.49%**（**2.5–14.6%**）
- intermediate curvature **2.86%**（**0.9–7.1%**）

でした。`|tilt|` median **0.0178 AUC** は `|curvature|` **0.0090** より大きく、paired Wilcoxon **p=0.00105**。amplitude は既存 relative-time persistence と強く対応し、slopeとは **rho=-0.773, p=1.44e-6**、areaとは **rho=+0.661, p=1.28e-4**。一方 amplitude と scale tilt は **rho=-0.017, p=0.931** でした。

さらに resolution opportunity を分けると、28 clades中 **7** は fine/coarse partition が同一で tilt は構造的に0。opportunity のある **21 clades**では **15 positive / 6 negative**、median fine−coarse tilt **+0.01998 AUC**、one-sided Wilcoxon **p=0.0192**、sign-test **p=0.0392**。しかし compression magnitude 自体は signed tilt を予測しませんでした（entropy loss: **rho=0.226, p=0.325** など）。

### 生態・進化解釈

昨日までの「flower-colour memory は時間とともに減衰する」に、今日は構造が一つ足されました。**how much history remains** と **at what phenotype scale it is visible** は別問題です。また fine distinction が存在することは fine-scale memory の必要条件にはなっても、その実現量を決めません。

ただしこれは既に開いた outcome の post-outcome exploratory reparameterization。frozen EL v0.3 の prospective evidence には昇格しません。

## 3. FCP / disttrait — 観測過程と biological organization を分ける境界が数値化

v0.10 は latent biological null のまま観測機構だけを変えました。MCAR、trait-only、position-only selection では matched-null rejection は **≤0.05**。しかし observation が trait×position に共同依存すると、matched-null rejection は **0.80–1.00**、species fixed-effect logistic も **1.00**、observed rows の within-species trait-position correlation は平均絶対値 **0.21–0.32** まで上がりました。

これは permutation が壊れたというより、**観測過程が retained sample に本当の関連を作った**という結果です。したがって「conditional calibration」と「latent biological validity」は別問題です。

v0.11では共有 quadratic curvature が正しいと effect=0.4 で common quadratic detection **1.00**ですが、50% species が curvature direction を反転すると **0.025–0.05**まで低下。direction-invariant matched-null は effect=0.8 の反転条件でも **0.85–1.00**を保持しました。

v0.12 multivariate でも同様で、effect=0.4・shared orientation なら common-vector **1.00** / matched-null **0.975–1.00**、full-circle orientation spread では common-vector **0.075** に対し matched-null **0.95–1.00**。つまり方法の優劣ではなく、**共有方向を問うのか、方向を問わず organization strength を問うのか**で estimand が違います。

第二 external transport の `Gammarus insensibilis` は **375 individuals / 3 populations**で、log metabolic-rate rho **-0.00683, p=0.68**、raw-rate sensitivity rho **0.01093, p=0.198**。San Francisco tree の positive transportに続いて、同じ inference layer が null も返すことが確認されました。

## 4. PAYOFF-B — interaction matching が evolutionary coordination barrier を作る候補

PR #145 は、migration と phenology を同じ moving environmental mismatch を閉じる二つの heritable axis として扱い、2D strategy lattice、replicator-mutator occupancy、two-lineage alternating substitutions、stochastic forcingを追加しました。

新しい mechanistic lead は、**両種が同じ intrinsic cost bias を持っていても、現在の interaction matching を壊す unilateral small move が不利なため、pair が matched mixed strategy に局所的にtrapされ得る**ことです。コードは local coevolution endpoint と coordinated matched-pair optimum の gap を `accessibility_gap` として測ります。

これは natural frequency claim ではなく synthetic mechanism result です。phase boundary の体系的mappingがまだ必要なので `まだ暫定` に留めます。ただし昨日の observational phase-locking programmeと合わせると、PAYOFF-B は「どの axis が最適か」から **どの adaptive route が locally accessible か**へ理論的に深まりました。

## 全リポ横断で昨日より何が一段進んだか

昨日は **within-system organization → cross-system transfer → universal law** を別endpointとして扱えるようになりました。今日はその一段下、**“transferやresponseが起こる機会がある”ことと、“実際にその情報・応答が実現する”こと**を分けられるようになりました。

- CHUN: fine distinctions が存在する **opportunity** と、fine-scale memory が実際に強くなる **realization** は別。
- BITA: visitor identityだけでなく、flower–bill の **access geometry** が robbery route の実現に関わる。
- TTF: same-orderという biological labelだけで比較すると、source **geometry** の違いを taxonomic transfer と取り違え得る。
- PAYOFF-B: globally better adaptive allocation があっても、unilateral move の **accessibility** が局所進化を止め得る。

> **ecological/evolutionary outcomes are not determined by state labels alone; they depend on the geometry of access, observation and locally available transitions that determines whether latent distinctions are realized.**

です。これは `state` を増やす議論ではなく、**state × accessibility / opportunity → realized outcome** という共通構造が複数の独立プロジェクトで見え始めた、という前進です。
