## 1. BITA — access-routing が2つの独立 visitor network で同じ方向に再現

昨日までは Ecuador bird network と Sakhalkar insect network を別々の corroboration として扱っていました。今日は raw rows を混ぜず、各 network が1つの標準化 rank association を出し、network を等重みする joint test が正式に閉じました。

### Network-specific effects

- Sakhalkar insects: **n=57 plant species**, Spearman **rho=0.346786**, permutation **p=0.0082**
- Aubert / EPHI birds: **n=1,378 bird × plant × site units / 18 sites**, site-adjusted **rho=0.350512**, within-site permutation **p=0.0001**
- equal-network Fisher-z mean: **rho_J=0.348651**
- stratified two-sided permutation: **p=0.0001**
- direction concordance: **2/2 networks positive**

追跡可能な result は `empirical/floral_defence_selectivity/results/joint_access_routing.json`。PR #228 の workflow で exact frozen result が再現されています。

さらに sparse pair-site を除いても、Aubert の minimum interaction count を 1→2→5 と上げるにつれて、joint rho は **0.3487 → 0.3757 → 0.3855**、すべて **p=0.0001**。minimum ≥5 でも Aubert は **702 units**残ります。したがって cross-network signal は one-off pair-site observations だけで作られていません。

### 生態学的問い

**legitimate floral access を制約する形態的不一致は、異なる visitor fauna でも exploitation を bypass / robbing route へ寄せるか。**

現在の2ネットワークでは Yes と整合します。これは「長い花筒が防御になる」という単純な量的効果より、**access geometry が interaction route を変える**という機構像です。

### 論文化すると

> *Across two independent insect and bird visitor networks, stronger constraints on legitimate floral access are associated with greater bypass/robbing propensity.*

までが強いです。**k=2 independent networks**なので、between-network heterogeneity、population-level network mean、全visitor networkへの一般化、因果効果はまだ言いません。

判定: **新規に支持された**。sparse-unit sensitivityにより **既存結論も強化**。

## 2. PAYOFF-B — phase correction は3 taxonへ広がったが、共通 actuator はまだない

PAYOFF-B の movement–phenology lane は、昨日の mule-deer controller signature から、barnacle goose と preregistered Eurasian wigeon まで同じ direct phase-retention coordinate `lambda` に置ける段階へ進みました。

### Direct phase-retention evidence

- mule deer: **152 animal-years / 72 individuals / 8 years**。start phase に対する speed response `kappa=0.01830 d^-1`、clustered **p≈1.2×10^-50**、direct phase transfer `lambda≈0.107`
- barnacle goose: Svalbard `lambda=-0.106`、Greenland `0.131`、Barents `0.494`
- Eurasian wigeon — preregistered third taxon: **224 consecutive staging transitions / 28 individuals**、`lambda=0.85994`, **SE=0.04509**, `H0: lambda=1` に対し **p=0.00190**

wigeon は「phase error をまったく補正しない `lambda=1`」を棄却しました。一方、より強い予測 **|lambda|<0.75 はFAIL**、stopover と travel-speed actuator prediction も非支持でした。したがって現在の正の主張は **phase-error retention/correction を共通座標で測れる**ことであって、全taxaが同じ強さ・同じ行動機構で補正することではありません。

### anthropogenic perturbation

industrial mule-deer archiveでは **64,539 GPS points / 137 animals / 253 animal-years**。primary G sampleは **188 animal-years / 103 animals**で、control-permeability G の median は small development **1.656**、large development **1.037**。clustered large-development shift in log G は **-0.476, p=0.017**、8/8 registered near/far definitionsで方向が一致し、step-level edge × large-development attenuation も **p=0.038**でした。

これは大規模developmentが phase correction / environmental tracking の透過性を弱めるという observational association と整合します。ただし stronger longitudinal deterioration は **year × large-development p=0.327**で非支持です。

### 生態学的問いと論文 claim

**移動個体は固定の「最適速度」を使うのか、それとも系ごとに phase error を変換・保持するfeedbackを持つのか。**

現在は後者がよく合います。

> *Phase retention provides a common cross-taxon coordinate for movement–phenology tracking, whereas actuator architecture and correction strength remain taxon/route specific.*

判定: wigeon prospective resultは **新規に支持された**。three-taxon coordinateは **既存結論が強化**。共通 actuator と stronger correction forecastは **未支持**。PRはdraftなので publication claim ceilingは維持します。

## 3. CHUN — 「最適resolution」ではなく coarse state 内に残る hierarchical memory

Flower-clades-51 の21 cladesで、同じ coarse flower-colour stateを共有するspecies pairだけを残し、近縁なpairほど同じ fine stateを共有するかを within-coarse permutation null に対して評価しました。

### visible-colour batch

- opportunity clades: **21**
- positive centered hidden-memory effect: **18/21**
- median centered effect: **+0.0270 AUC**
- bootstrap 95% interval: **+0.0084 to +0.0453**
- one-sided Wilcoxon **p=3.34×10^-5**
- sign-test **p=7.45×10^-4**

この hidden effect は global scale tilt とほぼ無関係（**rho=0.110, p=0.634**）。global fine-minus-coarse tilt が負の6 cladesでも **5/6**は正の hidden fine memory を持ちます。

### biochemical bridge — Petunieae

47-tip frozen frameで coarse anthocyanidin presence/absenceを固定した後も、fine compound identity は、

- observed conditional AUC **0.70180**
- within-coarse null mean **0.51385**
- centered effect **+0.18794 AUC**
- one-sided permutation **p=0.0001**

でした。

さらに synthesis は別estimandの external radiations **Linoideae / Angraecinae / Antirrhineae の3/3**でも conditional fine-state organization があることを整理しています。ただしこれらは statistic が違うため p値をpoolしません。

### 生態・進化解釈

negative-lookingだった「universal resolution optimumがない」という結果を、より正の構造に置き換えられます。

**coarse state は広い歴史情報を保持しながら、その内部に finer phenotype identity の追加の phylogenetic organization が残り得る。**

つまり evolutionary memory は global scale-optimum というより **hierarchical / nested** です。

ただし Flower-clades analysis は post-outcome pilot-exposed、Petunieae は retrospective same-source。prospective Ruellia test は tree provenance blocker のため outcome未開封です。したがってこれは **既存 exploratory conclusion が強化された**のであって、prospective universal lawではありません。

## 4. SCH — 同じ floral trait への net selection が local context で反転する事例が増えた

H2 は local context evidence をかなり増やしました。Trifolium では、

- inflorescence production: ambient herbivory **beta=0.91, p<0.001** → reduced herbivory **beta=1.34, p<0.001**
- flowering time among cyanogenic genotypes: open pollination **beta=-0.03, p=0.77** → supplemental pollination **beta=+0.19, p=0.03**

Erysimum の Table 5 では4 canonical corolla axesについて18 population-level total direct selection coefficientsを回収。たとえば、

- corolla tube width: Em01 **+0.058** vs Em21 **-0.079**、両方 significant
- corolla shape: Em01 **-0.091** vs Em21/22/23 **+0.149 / +0.208 / +0.256**、いずれも significant

Erysimum を含めた H2 state は **44 local cases / 37 plant-performance cases / 11 axes / 6 independent clusters / 10 repeated axes**。case count、axis count、repeated-axis gateはPASSですが、独立cluster breadthは **6<8**でFAILです。

### 生態学的意味

同じ trait coordinate でも local biotic/geographic context により **net selection の強さ・符号が変わる**ことを示す source-resolved examples はかなり増えました。これは geographic mosaic / context-dependent selection と整合します。

ただしこれらは total net selection であり、各populationで pollinator と antagonist の component geometry を同定していません。また6 clustersしかないため prevalence / mixed-effects macro modelもまだ開けません。

判定: **既存の context-dependence 結論が強化された**。一般化はまだ暫定。

### TTF — Lepidoptera trait similarity は transferability を予測しなかった

TTF は prior identity-opened Phase-1 の250 speciesを除外し、character-mask後 **240 species**でexact survivor geometryを再qualification。private Type-I **10/500**（Wilson 95% upper **0.0364**）、geometry-confounded trap **18/500**（upper **0.0562**）、trait-gradient positive **435/500**（lower **0.8377**）を通してから one-shot empirical outcome を開きました。

primary result は、

- statistic **-0.0166475**
- worst-case envelope **p=0.89**
- **110 finite evaluation targets**
- target correlations: **50 positive / 60 negative**
- decision: `NO_DETECTED_POSITIVE_TRAIT_SIMILARITY_GRADIENT`

です。

つまり、少なくともこの species-disjoint Lepidoptera panel では **粗い trait similarity が geography-conditioned genetic-transfer performanceを高める**という予測は支持されませんでした。

post-result exploratory decompositionでは **2,428 supported target-source pairs**の variation のうち、source exportability **0.478%**、target receptivity **1.364%**、pair-specific/residual **98.158%**。source/target identityを足しても 10-fold pair-CV RMSE は **0.265592 vs 0.265568**で改善しません。ただしこれは exploratoryで confirmatory p値はありません。

この結果は「traitは遺伝的連結性と無関係」という一般否定ではなく、**transferabilityを coarse species property として固定するモデルがこのpanelでは働かなかった**という反証です。

## 全リポ横断で昨日より何が一段進んだか

昨日は **state / opportunity / access / observation geometry が latent distinctions を realized outcomeに変える**という構造まで来ました。

今日は、その realization が **どの抽象度なら系を越えて再現するか**が見えてきました。

- BITA: raw morphologyやfaunaは違っても、**access constraint → bypass routing** という standardized process directionは2 networkで再現。
- PAYOFF-B: speciesやrouteごとの係数は違っても、**phase retention `lambda`** という response coordinateは3 taxonで測れる。一方 actuatorは共通ではない。
- CHUN: coarse/fineのwinnerは一定でなくても、**coarse state内にfine identityの追加memoryが残る**という nested architectureは複数 representationで見える。
- SCH:同じ traitでも local net-selection coefficientは符号まで変わり得る。
- TTF:一方で、coarse species trait similarityをそのまま transferability predictorにすると fresh frozen testで失敗する。

したがって今日の横断結論は、

> **generalization は raw trait label や universal parameter より、条件づけられた process coordinate / relational architecture のレベルで成立しやすい。**

ということです。

これは「全部context-dependent」という曖昧な話ではありません。何を共通座標にすれば再現し、何を固定的なspecies propertyやuniversal constantとして扱うと壊れるかが、各repoで別々に測れています。

## 次に回収すべき解析 / 検証

最優先は **BITA の3つ目の independent visitor network**です。今の joint resultは k=2 なので、同じ estimandを outcome前にfreezeして第三faunaで再現できれば、「2 examplesのjoint test」から network-level generalityへ初めて進めます。既存2networkのp値をさらに磨くより情報価値が高いです。

TTF は今回の negativeをretuneで救わず、exploratoryに見えた **pair-specific relational structure**を次のfresh hypothesisにするべきです。source×target habitat/host/resource similarityなど、pair-level covariatesを response前にfreezeし、別panelで検証する価値があります。

CHUN は retrospective evidenceを増やすより、既にfreezeした **Ruellia within-coarse hidden-memory test**の authoritative tree provenanceを解決し、outcome未開封のまま一度だけ実行するのが最大情報利得です。

EGWEE は G_adult–G_offspring を **3/5→5/5**まで同じ preregistered pair familyで回収し、それまではmeta endpointを開かない。BALANCE / ESDM / SDMR も現在の coder / validation / empirical firewallsを維持します。
