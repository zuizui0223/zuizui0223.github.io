## 1. IWE — strict timing–fitness evidence が3 interaction classesすべてに入った

今日はIWEが一番大きく進みました。screening inclusion と strict-H1 admissionを分離し、`data/extraction/direct_effects.csv` と `data/registry/strict_h1_adjudications.csv` に、partner activityで**事前に順序づけられる one-sided timing window**と final reproductive outcomeだけを strict effectとして入れています。

### Mutualist

`IWE029` — *Stigmaphyllon paralias* × oil-collecting *Centris* bees。peak window では legitimate visit marks **7.5% (134 flowers)**、late windowでは **93.6% (140)**。natural-pollination seed set の flowering-time coefficientは **log odds +1.55, SE=0.25, n=173**。late high-pollinator windowの方がseed setが高く、再構成95% Wald CIは **[1.06, 2.04]**、odds ratio換算で約 **4.71**です。

`IWE027` — *Phyllodoce aleutica* × bumblebees。2007だけを contemporaneous partner-activity yearとして採用し、worker emergence後の high-overlap middle window と early low-visit windowを比較。HIS は **Hedges g=+0.8518, var=0.08851, n=48**、GOS は **g=+1.0039, var=0.09158, n=48**。再構成95% CIはそれぞれ約 **[+0.269,+1.435]** と **[+0.411,+1.597]**。2行は同じ `DEP_IWE027_TAISETSU_2007` に属し、独立2研究とは数えません。

### Antagonist

`IWE011` — *Peucedanum multivittatum* × seed-predating moth *Phaulernis fulviguttella*。moth ovipositionが集中するmid-Julyの high-overlap HA と Augustの low-overlap HD を比較すると、final intact-fruit set は HA **0.13 ±0.19 SD, n=177**、HD **0.40 ±0.29, n=127**。高い predator overlap の効果は **Hedges g=-1.1368, var=0.01560, n=304**、再構成95% CIは約 **[-1.382,-0.892]** です。

### Mixed pollinating seed predator

`IWE015` — *Silene stellata* × *Hadena ectypa*。Hadena-dominant early window と co-pollinator-dominant late windowの successful fruits は、2012 **g=-0.0454 [約 -0.405,+0.315]**、2013 **g=+0.0225 [約 -0.349,+0.394]**。両年ともほぼ0で、しかも同一 `DEP_SILENE_STELLATA_HADENA_MLBS` clusterです。

### 何が新しく言えるか

**新規に支持された system-level conclusion** は、mutualist systemsでは高いpartner overlapが高いplant reproductionと整合し、antagonist systemでは高いoverlapが低いfinal reproductionと整合することです。mixed pollinating seed predatorでは単純なmonotonic advantageは見えません。

さらに重要なのは、**standardized mean difference が初めて mutualist / antagonist / mixed の3 preregistered classesすべてに存在する effect familyになった**ことです。しかし各SMD classはまだ **1 independent dependence cluster** しかなく、reference gateは最低2 clusters/classを要求します。したがって「interaction typeで平均効果が異なる」というH1は **まだ NOT_EVALUABLE**。方向の並びは非常に示唆的ですが、meta-moderationとしてはまだ言いません。

### 生態学的問い / 機構 / 論文化

問いは **「partnerとの時間的重なりは、mutualistなら利益、antagonistならコスト、benefitとcostを同じpartnerが持つmixed systemなら相殺としてfitnessへ現れるか」** です。

現時点の機構像は、timingそのものではなく **interaction signが timing overlap のfitness consequenceを変換する**、というものです。

論文化すると現在の上限は、

> Strict partner-activity windows yield positive timing–fitness contrasts in mutualist systems and a negative contrast in an antagonist system, while one mixed pollinating-seed-predator programme is near zero; formal interaction-class moderation remains untested because each class has only one independent SMD cluster.

です。

## 2. TTF — larval host-resource geography まで入れても cross-species genetic transfer は予測できなかった

昨日は butterfly trait panel で coarse trait similarity gradient が **statistic=-0.01665, p=0.89** と非支持でした。今日はその後継として、species attributesではなく **source×target relational ecology**に近い native larval host-resource geographyを、完全にspecies-disjointな moth-rich panelで一度だけ開封しました。

host-resource panelは response-blind 500 speciesからcharacter mask後 **431 survivors**、inherited **213 train / 218 eval**、geographically supported eval targets **204**、target-source pairs **12,358**。exact-survivor qualificationは private Type-I Wilson upper **0.0112**、geometry trap **0.0415**、host-breadth trap **0.0821**、true host-resource positive power Wilson lower **0.9042**でPASSしています。

それでも primary one-shot result は、

- statistic **-0.0070448**
- worst-case envelope **p=0.698**
- finite target correlations **201**
- positive / negative targets **101 / 100**
- median target correlation **+0.001706**

で、decisionは `NO_DETECTED_POSITIVE_HOST_RESOURCE_GEOGRAPHY_GRADIENT` でした。

### 生態学的意味

**同じnative larval host geographyを共有するLepidopteraほど、IBDを越えた空間遺伝構造が似る**という予測は、このqualified domainでは支持されませんでした。host breadthだけでなく realized host-resource geographyまで入れてもダメだったので、単純なresource-constrained transfer hypothesisはかなり弱くなりました。

ただしこれは「寄主植物は遺伝構造に影響しない」という結論ではありません。speciesごとの host use は genetic structureを作り得ますが、**その情報をsource speciesからtarget speciesへ転移する共通mappingが検出できなかった**という結論です。

昨日の trait-gradient negative と合わせると、TTFの次の問いはさらに絞られます。次に必要なのは説明変数を追加して同じpanelを救済することではなく、**pair-specific repeatabilityそのものがfresh panelで存在するか**、存在するならどのrelational coordinateが事前にそれを予測するか、です。

判定: **新規反証**。post-result retuningは不可。

## 3. SCH — ecological breadth はPASSしたが、同じ数値を平均できる研究はまだ足りない

`PR #74` で2 independent clustersが追加されました。

*Polygala vayredae* のnectar-gland effect on successful pollinationは、Montmajor **b=0.311, p=0.001**、Serrat dels Boixos **b=0.169, p=0.123**、Colldecarrera **b=0.255, p=0.011**。これは reproductive-component effectで、final-fitness selection gradientではありません。

*Tanacetum vulgare* は **n=95** の germination-performance proxyで、chemotype **chi-square=10.44, df=4, p=0.034**、plot type **p=0.434**、pollinator visits association **p=0.025**、florivore visits **p=0.356**。seed setを測っていないため、これもselection gradientには昇格しません。

これでH2は、

- total local cases **49**
- plant-performance cases **42**
- canonical axes **14**
- independent clusters **8**
- repeated axes **11**

となり、**broad ecological breadth gateは全PASS**しました。

しかし commensurate estimand familyを見ると、最大の `TOTAL_SELECTION_EFFECT` は **30 cases / 8 axes / 3 independent clusters**にしかなりません。したがって `estimand-family modelability = FAIL`、`numeric pooling = FAIL`、primary numeric H2 modelは **FAIL_CLOSED** のままです。

さらに frozen 29-record full-text-pending queueを outcome-blindに全件監査しましたが、**新しい TOTAL_SELECTION_EFFECT promotionは0/29**。主な失敗理由は no shared trait coordinate 8、not primary empirical 7、no common fitness-selection estimand 3、no common reproductive outcome 3などでした。

### 生態学的解釈

これはnegativeだけではありません。**同じfloral traitがlocal biotic/geographic contextで異なる performance / selection responseを示す evidence breadthは、8 independent clustersまで広がった**。一方で、そのecological diversityを無理に「平均 selection effect」に圧縮すると estimandが壊れることも同時に分かりました。

したがって論文化の正しい主張は、

> Repeated context-dependent floral-performance and selection responses are ecologically broad, but a cross-system mean total-selection effect is not yet identified because commensurate estimands remain sparse.

です。

判定: **既存結論が強化された**。pooled magnitude / prevalenceはまだ言わない。

## 4. 新規 `Structural` — connectivity は universal scalar ではなく operator × endpoint で型付けすべき、をsyntheticに明示

今日新しく作られた [`Structural`](https://github.com/zuizui0223/Structural) は、EOG内で閉じていた Structural/reference-adequacy paperを独立repoへ移したものです。移管自体は **scientific result changed=false** で、A-Islands / Tanzaniaの既存frozen結果を再実行・再解釈していません。

既存frozen boundaryは、A-Islands original conditional concordance **0.6177466**、strong referenceでは `C-R3` log-loss increment **+0.0034852**（lower is betterなのでadverse）、Tanzania primaryもmatrix-aware strong reference beyondでadverse、というものです。これらは今日の新規 empirical supportには数えません。

一方post-closure developmentは、connectivityを

`C^(level, operator, endpoint, origin | reference)`

として型付けし、pollen endpoint と whole-individual endpoint のknown-truth worldsを別々に作っています。synthetic held-out predictionでは、pollen truthのとき matching pollen modelは reference MSE **0.11268 → 0.000522**、mismatched whole-individualは **0.11219**でほぼ改善なし。whole-individual truthでは逆に reference **0.12398 → matching 0.000520**、mismatched pollen **0.12338**。collapsed mean connectivityは両worldで一部signalを拾うものの **MSE≈0.063–0.064** と matching typed coordinateより明らかに悪いです。

これは自然界の結果ではありませんが、今日の横断テーマをかなり明確にします。**「関係変数」なら何でも良いのではなく、何が伝播するoperatorなのか、どのendpointを予測するのかを対応させないと transferability は保証できない。**

判定: **新規 synthetic/method result**。natural prevalenceやreal movement kernelは主張しません。

## 5. SLK — invasion criterionを内部frequency-response形状から切り離し、有限頻度実験へ落とした

SLKはempirical resultではなく理論が一段進みました。UTA1.8では

`Delta(p,E)=Phi(E)+H(p,E)`

とし、rare-D / resident-D endpoint offsetsを `h_R` / `h_D` とすると、deterministic invasionは

- rare D invasion: `Phi+h_R>0`
- resistance to rare S: `Phi+h_D>0`

だけで決まります。interiorのlinear / quadratic / symmetric shapeを仮定しません。

UTA1.9ではexact `p=0,1` を観測しなくても、near-endpoint `epsilon` からcertifyできるようにしました。1点なら誤差は `O(epsilon)`、2点 extrapolator

`Delta_R_hat = 2 Delta(epsilon) - Delta(2 epsilon)`

とcurvature boundを使えば誤差は **O(epsilon^2)** になります。

一方 D0 confirmatory designのreviewでTOST power formulaを修正し、例 `sd=1, margin=0.5, alpha=0.05, power=0.80` のpaired nは **25→35**へ増加。15 stochastic endpointsのall-pass target 0.80を保守的に満たすreferenceではpaired **n=68**、two-group **136/group**まで必要になりました。これはbiological D0 resultではなく、prospective design repairです。

判定: **理論・設計が強化**。生物学的G1–G9/D0 resultは未開封。

## 全リポ横断で昨日より何が一段進んだか

昨日は、**raw traitやuniversal parameterより、process coordinate / relational architectureの方が一般化しやすい**という方向が見えました。

今日はその命題自体に条件が付きました。

TTFでは `host-resource geography similarity` というsource×target relational variableまで使っても transfer predictionは失敗しました。つまり **relationalであるだけでは足りない**。

Structuralのknown-truthでは、同じ“connectivity”でも pollen operator と whole-individual operatorを取り違えると held-out gainがほぼ消え、endpointに合った operatorだけが大きく改善しました。SCHでは同じecological storyでも final selection / reproductive component / germination proxyを混ぜると numeric estimandが壊れる。IWEではeffect familyとdependence clusterを揃えたときに初めて interaction-class comparisonを開ける設計になりました。

したがって今日の横断結論は、

> **Generalization requires not just a relational variable, but an endpoint-matched biological operator, a commensurate estimand, and independent replication at that level.**

です。

研究全体として昨日より一段進んだのは、「何をrelationalにすればよいか」から、**どの関係がどのendpointを生成するのかを型付けし、その同じestimandを独立系で反復できるか**へ問いが移ったことです。

1. **IWE:** strict-H1 real corpusが3 interaction classesすべてに到達。mutualist SMD **+0.852 / +1.004**、antagonist **-1.137**、mixed **-0.045 / +0.023**。方向は仮説的に非常に意味があるが、各class 1 clusterなのでmoderationはまだ開けない。

3. **SCH:** ecological breadthは **49 cases / 14 axes / 8 clusters**でPASSした一方、commensurate TOTAL_SELECTION_EFFECTは **30 cases / 8 axes / 3 clusters**。**evidence breadth ≠ poolable estimand breadth** が数値で確定した。

## 次に回収すべき解析 / 検証

**IWE** は一番明快です。effectをさらに変換して無理にpoolするのではなく、SMD scaleで mutualist / antagonist / mixed の **2 independent clusters/class** を先に揃える。その時点で初めてinteraction-class moderationを開くべきです。特にmixed classの2つ目の独立programmeが情報価値最大です。

**TTF** はhost-resource resultをretuneで救わない。次は同じresponseを説明するcovariate huntではなく、fresh disjoint panelで **pair-specific genetic-transfer scoreそのもののsplit-half repeatability** を先に確認する。repeatabilityがなければ relational predictor hunt自体を止められます。repeatabilityがあれば、その後で habitat similarity / historical co-exposure 等をresponse前freezeして検証するのが筋です。

**SCH** は463 unscreened titlesを frozen priority ruleで進めてもよいですが、目的はcase数ではなく **TOTAL_SELECTION_EFFECT independent clusters 3→必要数**。component/performance proxyを追加してbreadthだけ増やしてもnumeric modelは開きません。

**BITA** は既存k=2 p値を磨かず、prospective Cape networkをそのまま実行。第三networkがnull/逆符号でも保持することがgenerality testの価値です。

**Structural** はDavis retrospective adapterをengineering用途に限定したまま、fresh systemでは outcome前に operator / endpoint / origin / equivalence marginをfreezeする。TTFの失敗と直接つながる次の実証になる可能性があります。

**SLK** は理論をこれ以上広げるより、finite-frequency endpoint certificationに必要な `M_R` / curvature bound / sampling precisionをPedicularisのreal calibrationでどこまで置けるかが次の実証ボトルネックです。
