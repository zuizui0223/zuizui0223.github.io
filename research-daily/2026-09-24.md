## 1. Izu Chapter 2 — RNG collisionを直しても regime-dependent determinant crossover は残った

今日の科学的な最重要更新です。post-freeze code reviewで、歴史的なseed構築

`run_seed = seed + rep*10000; mainland = run_seed+100000; island = run_seed+200000`

には、意図した **192 scenario×replicate streamsのうちdistinct integer streamsが106しかなく、86 collision pairs** があることが判明しました。PR #361はこれを `numpy.random.SeedSequence` の階層 `master seed → replicate → scenario → copy` に置き換え、宣言されたk=16までの **18,432 child streams / 18,432 unique / 0 collisions** に修正しました。生物学的パラメータ、6 master seeds、96 realizations、trait grid、k={1,2,4,8,16} は変更していません。

collision-free six-seed ensemble の baseline は、

- mixed-sign states: median **45.5**, range **43–59**
- starting-position fraction S: median **0.0311**, range **0.0201–0.0409**
- community-realization fraction C: median **0.7427**, range **0.6978–0.7873**
- nonadditivity fraction I: median **0.2282**, range **0.1864–0.2676**

でした。

### 何が残ったか

prespecified rank-crossover decision rule は **PASS** のままです。system sizeが増えるにつれてSが増え、Cが減るという大筋は保持され、

- **k=4:** S>C in **4/6 seeds**
- **k=8:** **6/6**
- **k=16:** **6/6**

となりました。k=16 median は **S=0.5353, C=0.1405, I=0.3203**。したがって、**大きなcommunityではstarting stateの寄与がcommunity realizationを上回り得る**というmechanistic existence result自体は、RNG correction後も残ります。

ただし以前の「k=4以降6/6で順位反転」という表現はもう使えません。unanimityは **k=8** からで、exact crossover kは明示的に **model-specific** です。

さらに exact realized-richness matchingでも、mean geometryは6/6 seedsでall-positiveへ動く一方、individual-level mixed realizationsは **55–64 / 96** 残りました。つまり richness matchingはcoarse mean regimeを動かしますが、**state × realized communityによるbranchingを消しません**。

### synchrony-depth sensitivityで変わったこと

natural-system synchrony axisもsampling depthの監査に入りました。1,000 prespecified draws中999 validで、six-bin rarefaction後のphi-only primaryは、

- all-source dispersion criterion pass: **0.9079**
- England removed all-criteria pass: **0.8909**
- England removed phi-span pass: **0.9329**
- phi-span median **0.4695**, 95% interval **[0.2844, 0.7739]**

でした。

Englandの3 systems自身はsix-bin化してもhigh synchronyを維持します。一方、**Englandを除くとhigh-synchrony edgeが成立しない**という以前の強いsource-leverage解釈は、equal-depth rarefactionでは支持されません。England-excluded phi spanは **93.3%** のdrawでgateを通ります。より強いjoint-coordinate secondaryのall-source passは **0.6106** なので、sensitivity自体は無視できません。

### 生態学的問い / 解釈 / 論文化

問いは、**同じcoarse interaction regimeの中で、community complexityが増えると detailed response を決める主因が realized community から starting stateへ移り得るか**です。

今日の答えは **Yes, but the finite-k boundary is less sharp than previously reported**。collision-free simulationでも determinant ordering の regime dependence は残り、richness matchingでもindividual branchingは消えません。しかし exact crossover location と natural synchrony source leverage は、実装・sampling depthに依存するため狭く報告すべきです。
